# Система Рабиновича–Фабриканта

## Обзор

**Система Рабиновича–Фабриканта (1979)** — модель модуляции волн
в неравновесных средах. Описывает взаимодействие трёх мод в плазме
или гидродинамике.

Демонстрирует **перемежаемость**: устойчивые квази-циклы сменяются
хаотическими всплесками. Это один из классических примеров перехода
к хаосу через перемежаемость (Pomeau–Manneville сценарий).

## Уравнения

```text
ẋ = y(z − 1 + x²) + γx
ẏ = x(3z + 1 − x²) + γy
ż = −2z(α + xy)
```

## Параметры

| Параметр | Диапазон | По умолчанию | Смысл |
|---|---|---|---|
| **α** | 0.5–2.0 | 1.1 | Диссипация в ż |
| **γ** | 0.5–1.5 | 0.87 | Усиление в ẋ и ẏ |

## Что смотреть в ChaosLab

### Attractor

Структура с двумя «лепестками» вокруг оси z. Хаотическое поведение
проявляется как случайные перескоки между лепестками.

**Рекомендации:**
- Палитра: Inferno
- Iterations: 5M
- Camera: Zoom = 35

### Bifurcation Diagram (γ)

Варьируйте γ от 0.5 до 1.5. При γ < 0.8 — периодика. При γ ≈ 0.87 —
начало перемежаемости. При γ > 1.0 — развитый хаос.

## Ожидаемые характеристики

Для α = 1.1, γ = 0.87:

| Метрика | Значение |
|---|---|
| λ₁ | ≈ +0.06 |
| D₂ | ≈ 2.1 |
| Тип перехода | Перемежаемость |

## Перемежаемость

**Перемежаемость** — режим, в котором длинные регулярные «ламинарные»
фазы сменяются короткими хаотическими всплесками. Средняя длина
ламинарных фаз растёт как `(γ_c − γ)^(−1/2)` вблизи порога.

Это **один из трёх** классических сценариев перехода к хаосу
(два других — удвоение периода Фейгенбаума и разрушение тора Рюэля–Такенса).

## Применения

- **Физика плазмы** — взаимодействие волн
- **Лазерная физика** — модуляция интенсивности
- **Гидродинамика** — переход к турбулентности
