# Система Шимизу–Мориоки

## Обзор

**Система Шимизу–Мориоки (1980)** — упрощённая форма системы Лоренца.
Получена заменой переменных, при которой исчезает один параметр, но
сохраняется топология аттрактора.

Широко используется в теоретических исследованиях как **«Лоренц без
Лоренца»** — та же динамика, но проще для анализа.

## Уравнения

```text
ẋ = y
ẏ = x − λy − xz
ż = −αz + x²
```

## Параметры

| Параметр | Диапазон | По умолчанию | Смысл |
|---|---|---|---|
| **λ** | 0.4–1.2 | 0.75 | Диссипация y (аналог σ у Лоренца) |
| **α** | 0.3–2.0 | 0.85 | Диссипация z (аналог β) |

## Что смотреть в ChaosLab

### Attractor

Двойной свиток, визуально похожий на Лоренца, но с более «чистой»
структурой — без лишних разветвлений.

**Рекомендации:**
- Палитра: Plasma или Emerald
- Iterations: 5M
- Camera: Zoom = 55

### Bifurcation Diagram (λ)

При λ < 0.6 — устойчивая точка. При λ ≈ 0.7 — первая бифуркация.
При λ > 0.8 — хаос.

## Связь с Лоренцом

Замена переменных: `x = X/√(σβ)`, `y = Y/√(σβ)`, `z = Z/σ`, `t' = t/√(σβ)`
приводит систему Лоренца к этой форме при определённых соотношениях
параметров. Однако Шимизу–Мориока имеет **два параметра** вместо трёх —
это делает её удобнее для численного анализа.

## Применения

- **Теоретическая физика** — упрощённые модели конвекции
- **Численный анализ** — быстрое тестирование методов
- **Педагогика** — проще для понимания, чем оригинал
