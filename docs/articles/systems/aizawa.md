# Аттрактор Аидзавы

## Обзор

**Аттрактор Аидзавы** — красивый сферический аттрактор с выраженной
центральной осью. Открыт Ёсинори Аидзавой в 1980-х годах при изучении
нелинейных колебаний.

Внешне напоминает вращающийся сфероид с осью, вокруг которой хаотично
«намотана» траектория. Хорошо подходит для демонстрации 3D-возможностей
камеры ChaosLab.

## Уравнения

```text
ẋ = (z − b)x − dy
ẏ = dx + (z − b)y
ż = c + az − z³/3 − (x² + y²)(1 + ez) + fzx³
```

## Параметры

| Параметр | Диапазон | По умолчанию | Смысл |
|---|---|---|---|
| **a** | 0.1–2.0 | 0.95 | Вертикальный кубический фактор |
| **b** | 0.1–2.0 | 0.7 | Смещение центра спирали по z |
| **c** | 0.1–2.0 | 0.6 | Постоянный сдвиг ż |
| **d** | 1.0–5.0 | 3.5 | Скорость вращения в плоскости xy |
| **e** | 0.05–0.5 | 0.25 | Связь радиального сжатия с высотой |
| **f** | 0.05–0.5 | 0.1 | Кубический коэффициент в ż |

## Что смотреть в ChaosLab

### Attractor

Классический сферический вихрь. Траектория вращается вокруг оси z,
одновременно медленно поднимаясь и опускаясь — картина выглядит почти
как «планета с кольцами».

**Рекомендации:**
- Палитра: Plasma или Sunset
- Iterations: 5M
- Camera: Yaw = 0.5, Pitch = −0.3, Zoom = 120

### Bifurcation Diagram (a)

Варьируйте a от 0.1 до 2.0. При a < 0.5 — устойчивый цикл, при a > 0.7 —
странный аттрактор, при a ≈ 1.3 — хаос становится тонким и разреженным.

### Lyapunov Map (a, b)

Хаотическая зона занимает большую часть области. При малых a и больших b
система «застывает» на спирали.
