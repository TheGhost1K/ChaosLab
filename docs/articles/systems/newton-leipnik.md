# Система Ньютона–Лейпника

## Обзор

**Система Ньютона–Лейпника (1981)** описывает вращение твёрдого тела
в магнитном поле. Её уникальная особенность — **два сосуществующих
странных аттрактора**: какой из них достигнет траектория, зависит от
начальных условий.

Такое поведение называется **мультистабильностью** — редкость даже
среди хаотических систем.

## Уравнения

```text
ẋ = −ax + y + 10yz
ẏ = −x − 0.4y + 5xz
ż = bz − 5xy
```

## Параметры

| Параметр | Диапазон | По умолчанию | Смысл |
|---|---|---|---|
| **a** | 0.2–0.6 | 0.4 | Диссипация по x |
| **b** | 0.05–0.30 | 0.175 | Диссипация по z |

## Два аттрактора

При классических параметрах (a = 0.4, b = 0.175) существуют **два**
разных странных аттрактора:

- **Аттрактор A** — достигается при x₀ > 0
- **Аттрактор B** — при x₀ < 0

Оба имеют схожую структуру, но зеркально отражены и имеют разную топологию.
Различие тонкое, но воспроизводимое.

### Bifurcation Diagram (a)

При a < 0.35 — система сходится к устойчивой точке.
При a ≈ 0.35 — бифуркация Хопфа.
При a > 0.4 — хаос с двумя аттракторами.

### Lyapunov Map (a, b)

Карта показывает границу между аттрактором A и B — тонкая фрактальная
структура в плоскости параметров.

## Физическая интерпретация

Модель описывает **динамику вращения твёрдого тела с магнитным моментом**
в постоянном магнитном поле. Уравнения Эйлера для свободного вращения
модифицированы диссипацией (коэффициенты a, b).

Два аттрактора соответствуют двум возможным «режимам» вращения —
например, синхронному и антисинхронному относительно поля.

## Применения

- **Спутники** — стабилизация вращения в магнитном поле Земли
- **Гироскопы** — анализ устойчивости
- **Квантовая механика** — аналогия со спиновыми системами

## История

R. B. Leipnik и T. Newton обнаружили эту систему при численном анализе
динамики твёрдого тела в магнитном поле. Они первыми заметили, что
**одна система может иметь несколько странных аттракторов** — это было
сюрпризом для теории динамических систем.

## Первоисточник

Leipnik, R. B., Newton, T. A. (1981). *Double strange attractors in rigid
