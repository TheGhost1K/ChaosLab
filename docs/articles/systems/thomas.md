# Система Томаса

## Обзор

**Система Томаса (1999)** — циклостатический поток с тригонометрической
связью компонент. Названа в честь Рене Томаса, изучавшего «циклостаз» —
свойство полей, в которых вектор «вращается» вокруг точки равновесия.

При b = 0.19 траектория заполняет «запутанный куб» — аттрактор имеет
форму слегка деформированного куба, по которому хаотично двигается.

## Уравнения

```text
ẋ = sin(y) − bx
ẏ = sin(z) − by
ż = sin(x) − bz
```

## Параметры

| Параметр | Диапазон | По умолчанию | Смысл |
|---|---|---|---|
| **b** | 0.05–0.4 | 0.19 | Диссипация: скорость «остывания» |

## Что смотреть в ChaosLab

### Attractor

Кубовидная структура. При медленном вращении камерой видно, что
траектория «ходит» по рёбрам куба, образуя решётку.

**Рекомендации:**
- Палитра: Emerald или Ice
- Iterations: 5M
- Camera: Zoom = 60

### Bifurcation Diagram (b)

Варьируйте b от 0.05 до 0.4. При b > 0.3 — устойчивая точка (sin(y) ≈ bx),
при b < 0.1 — «замороженный» хаос.

## Особенность системы

Полная симметрия относительно циклической перестановки компонент
(x → y → z → x). Это даёт системе три «эквивалентных» оси и делает её
удобной для изучения симметрийных свойств хаоса.

## Применения

- **Симметрийный анализ** хаотических систем
- **Педагогика** — простой пример тригонометрического хаоса
- **Художественная визуализация** — «куб Томаса» красиво смотрится в 3D
