# Отображение Клиффорда

## Обзор

**Отображение Клиффорда** — декоративное хаотическое отображение
с плавными структурами. Не имеет физического происхождения; используется
для визуализации математически красивых форм.

Структура сильно зависит от параметров — от простых замкнутых кривых
до сложных «кружевных» узоров.

## Уравнения

```text
xₙ₊₁ = sin(ayₙ) + c·cos(axₙ)
yₙ₊₁ = sin(bxₙ) + d·cos(byₙ)
```

## Параметры

| Параметр | Диапазон | По умолчанию | Смысл |
|---|---|---|---|
| **a** | −3…3 | −1.4 | Частота синуса и косинуса по x |
| **b** | −3…3 | 1.6 | Частота по y |
| **c** | −3…3 | 1.0 | Амплитуда косинуса в x' |
| **d** | −3…3 | 0.7 | Амплитуда косинуса в y' |

## Что смотреть в ChaosLab

### Attractor

Сложные «цветочные» структуры. При разных параметрах получаются разные
геометрические формы: линзы, бабочки, кружева.

**Рекомендации:**
- Палитра: Rainbow
- Iterations: 200K
- Camera: Zoom = 200

### Vector field overlay

Включите **Vector field overlay** — увидите направление потока поверх
аттрактора. Помогает понять, какие области притягивают, а какие
отталкивают.

## Ожидаемые характеристики

| Метрика | Значение |
|---|---|
| λ₁ | ≈ +0.4 |
| D₂ | ≈ 1.9 |
| Область | ограничена, x, y ∈ [−2, 2] |

## Параметрические режимы

Отображение Клиффорда известно своей **богатой параметрической
структурой**:

- **a = −1.4, b = 1.6, c = 1.0, d = 0.7** — классический «цветок»
- **a = 1.7, b = 1.7, c = 0.6, d = 1.2** — «звёзды»
- **a = −1.8, b = −2.0, c = −0.5, d = −0.9** — «кружево»

## Применения

- **Компьютерная графика** — генерация текстур
- **Художественная визуализация** — декоративные фракталы
- **Педагогика** — пример тригонометрического хаоса
