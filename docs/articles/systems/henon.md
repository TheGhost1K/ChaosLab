# Отображение Эно

## Обзор

**Отображение Эно** (Michel Hénon, 1976) — одно из самых изученных
двумерных дискретных отображений. Модель звёздной динамики, порождающая
странный аттрактор с фрактальной структурой.

## Уравнения

```text
xₙ₊₁ = 1 − a·xₙ² + yₙ
yₙ₊₁ = b·xₙ
```

## Параметры

| Параметр | Диапазон | По умолчанию |
|----------|----------|--------------|
| **a** | 0.8–1.5 | 1.4 |
| **b** | 0.1–0.4 | 0.3 |

## Структура аттрактора

Классический аттрактор при a = 1.4, b = 0.3 — **фрактальное множество
Кантора** из бесконечно тонких кривых. При большом увеличении
проявляется самоподобная структура.

## Что смотреть

### Attractor

При малых итерациях — одна кривая. При 5M+ итераций — плотная
фрактальная структура с «полосами».

### Bifurcation (a)

При b = 0.3 даёт каскад удвоения и хаос.

### Return Map

xₙ → xₙ₊₁. Даёт параболообразную кривую, похожую на логистику.

## Ожидаемые характеристики

Для a = 1.4, b = 0.3:

| Величина | Значение |
|----------|----------|
| λ₁ | **+0.419** |
| λ₂ | −1.623 |
| Σλᵢ | log\|b\| = −1.204 |
| D₂ | **1.26** |
| D_KY | 1.26 |

Сумма показателей Ляпунова — **инвариант** для отображений: она равна
логарифму |детерминанта якобиана| = log|b|.

## Фрактальная размерность

D₂ ≈ 1.26 — между 1 (кривая) и 2 (плоскость). Это означает, что
аттрактор **фрактал**: он «толще» кривой, но «тоньше» плоскости.

## Применения

- Модель звёздной динамики (сжатие Пуанкаре)
- Тест алгоритмов вычисления фрактальной размерности
- Эталон для сравнительного анализа

## Первоисточник

Hénon, M. (1976). *A two-dimensional mapping with a strange attractor*.
Communications in Mathematical Physics, 50(1), 69–77.
