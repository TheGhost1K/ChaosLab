# Отображение Tinkerbell

## Обзор

**Отображение Tinkerbell** — двумерное хаотическое отображение с
уравнениями, порождающими структуру «крыльев бабочки». Название —
аллюзия на фею Динь-Динь из «Питера Пэна».

Отображение является **полиномиальным** (в отличие от Clifford
и De Jong, использующих тригонометрию), что делает его удобным
для теоретического анализа.

## Уравнения

```text
xₙ₊₁ = xₙ² − yₙ² + axₙ + byₙ
yₙ₊₁ = 2xₙyₙ + cxₙ + dyₙ
```

## Параметры

| Параметр | Диапазон | По умолчанию | Смысл |
|---|---|---|---|
| **a** | 0–1.5 | 0.9 | Линейный коэффициент x в x' |
| **b** | −1.5–0 | −0.6013 | Линейный коэффициент y в x' |
| **c** | 0–4 | 2.0 | Линейный коэффициент x в y' |
| **d** | 0–1.5 | 0.5 | Линейный коэффициент y в y' |

## Математический интерес

Tinkerbell — один из примеров **полиномиальных отображений 2-й степени**,
дающих хаос. Его структура близка к Hénon map, но с более сложной
линейной частью.

**Ключевое свойство:** отображение обратимо (det J ≠ 0), что делает
его более «чистым» математическим объектом, чем необратимые
отображения (Clifford, De Jong).

## Применения

- **Теория динамических систем** — пример полиномиального хаоса
- **Компьютерная графика** — декоративные структуры
- **Педагогика** — визуально понятный пример
