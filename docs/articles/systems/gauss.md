# Отображение Гаусса

## Обзор

**Отображение Гаусса** (continued fraction map) — отображение, естественно
возникающее в **теории цепных дробей**. Связывает иррациональное число
с последовательностью его неполных частных.

Обладает **эргодической инвариантной мерой Гаусса–Кузмина** — одним из
первых примеров явной инвариантной меры в эргодической теории.

## Уравнение

```text
xₙ₊₁ = frac(α/xₙ + β)
```

где `frac(y)` — дробная часть y.

## Параметры

| Параметр | Диапазон | По умолчанию | Смысл |
|---|---|---|---|
| **α** | 0.5–3.0 | 1.0 | Масштаб отображения |
| **β** | 0.01–0.5 | 0.1 | Дополнительный сдвиг |

### Cobweb

**Гиперболический** вид: график функции `1/x` на отрезке. Итерации
образуют характерный узор, связывающийся с continued fractions.

## Инвариантная мера Гаусса–Кузмина

Плотность:

```text
ρ(x) = 1 / (ln(2) · (1 + x))
```

**Уникальное свойство:** эта мера **точная** — она удовлетворяет
уравнению Перрона–Фробениуса аналитически. Для большинства отображений
инвариантная мера известна только численно.

## Связь с цепными дробями

Любое иррациональное число x ∈ (0, 1) можно записать как:

```text
x = 1/(a₁ + 1/(a₂ + 1/(a₃ + ...)))
```

где aᵢ — натуральные числа. Отображение Гаусса переводит x в a₁ и
сдвигает цепную дробь на один уровень. Это — **символическая
динамика** continued fractions.

## Применения

- **Теория чисел** — статистика неполных частных
- **Приближение иррациональных** — теория Диофанта
- **Квантовый хаос** — модель для изучения спектральных свойств
- **Эргодическая теория** — эталон для аналитики
