# Система Лэнгфорда

## Обзор

**Система Лэнгфорда (1983)** — квазипериодический аттрактор на **торе**.
Демонстрирует переходы между устойчивыми точками, предельными циклами,
торами и хаосом при изменении параметров.

Названа в честь В. Ф. Лэнгфорда, изучавшего взаимодействие бифуркаций
Хопфа и стационарных состояний.

## Уравнения

```text
ẋ = (ν − 1)x − y + xz
ẏ = x + (ν − 1)y + yz
ż = μz − (x² + y² + z²) − γz³
```

## Параметры

| Параметр | Диапазон | По умолчанию | Смысл |
|---|---|---|---|
| **ν** | 0.7–1.2 | 0.85 | Скорость вращения в xy |
| **μ** | 0.4–1.2 | 0.85 | Усиление по z |
| **γ** | 0.1–1.0 | 0.5 | Кубическая диссипация z |

## Что смотреть в ChaosLab

### Attractor

При ν = 0.85, μ = 0.85, γ = 0.5 система лежит на **двумерном торе** —
замкнутой поверхности. Траектория никогда не повторяется, но и не
хаотична.

**Рекомендации:**
- Палитра: Rainbow
- Iterations: 10M (тор заполняется медленно)
- Camera: Zoom = 60

### Power Spectrum

**Ключевое отличие от хаоса:** спектр содержит **дискретные пики**,
а не широкополосный шум. Нажмите **Power Spectrum** — увидите чистые
пики на рациональных частотах.

### Bifurcation Diagram (μ)

Варьируйте μ от 0.4 до 1.2. При малых μ — устойчивая точка, при
μ ≈ 0.7 — предельный цикл, при μ = 0.85 — квазипериодика, при μ > 1.0 —
хаос.

## Квазипериодика vs хаос

**Квазипериодика** — это движение на **N-мерном торе** (N ≥ 2).
Спектр содержит рационально независимые частоты. λ₁ = 0.

**Хаос** — движение на **странном аттракторе**. Спектр широкополосный.
λ₁ > 0.

Различение требует методов спектрального анализа — ChaosLab даёт эту
возможность через **Power Spectrum** и **Resonance**.

## Применения

- **Теория синхронизации** — квазипериодические генераторы
- **Астрофизика** — орбитальные резонансы
- **Педагогика** — пример перехода «точка → цикл → тор → хаос»
