# Система Дадраса

## Обзор

**Система Дадраса (2009)** — трёхспиральный хаотический аттрактор.
В отличие от Лоренца и Chen (у которых по 2 «крыла»), эта система имеет
**три симметричных крыла**, обходящихся вокруг центра.

Открыта С. Дадрасом в 2009 году при поиске новых хаотических систем
с простой квадратичной структурой.

## Уравнения

```text
ẋ = y − ax + byz
ẏ = cy − xz + z
ż = dxy − ez
```

## Параметры

| Параметр | Диапазон | По умолчанию | Смысл |
|---|---|---|---|
| **a** | 1–5 | 3 | Линейная диссипация x |
| **b** | 1–5 | 2.7 | Квадратичная связь yz |
| **c** | 1–3 | 1.7 | Линейный рост y |
| **d** | 1–3 | 2 | Связь xy с ż |
| **e** | 5–12 | 9 | Диссипация z |

## Что смотреть в ChaosLab

### Attractor

Трёхспиральная структура. Траектория быстро перескакивает между
тремя «крыльями», что даёт характерную «плотную» картину.

**Рекомендации:**
- Палитра: Rainbow или Sunset
- Iterations: 5M
- Camera: Yaw = 0.5, Pitch = −0.3, Zoom = 55

### Bifurcation Diagram (a)

При a > 4 — устойчивая точка. При a < 2 — периодика. Хаос — в узкой
полосе a ∈ [2.5, 3.5].
