# Система Рёсслера

## Обзор

**Система Рёсслера** (Отто Рёсслер, 1976) — простейший хаотический поток
с ленточным аттрактором. Часто используется как «второй пример» после
Лоренца, потому что она визуально проще, но при этом сохраняет все
признаки странного аттрактора.

## Уравнения

```text
ẋ = −y − z
ẏ = x + ay
ż = b + z(x − c)
```

## Параметры

| Параметр | Смысл | Диапазон | По умолчанию |
|----------|-------|----------|--------------|
| **a** | Нелинейность | 0.05–0.5 | 0.2 |
| **b** | Внешний форсинг | 0.05–2.0 | 0.2 |
| **c** | Параметр растяжения | 1–20 | 5.7 |

## Динамика при изменении c

- **c < 4** — устойчивая точка или предельный цикл
- **c ≈ 4.2** — первая бифуркация удвоения периода
- **c > 4.6** — странный аттрактор (хаос)
- **c > 6** —- многослойный аттрактор с фрактальной структурой

## Что смотреть

### Attractor

Одна лента, которая растягивается, складывается и накладывается сама
на себя. Ключевая особенность — расстояние между соседними слоями
уменьшается экспоненциально.

**Рекомендации:** палитра Emerald или Ice, Iterations 3M.

### Bifurcation Diagram (c)

Варьируйте c от 1 до 20 — каскад удвоений и переход к хаосу при c ≈ 4.6.

## Применения

- Модель химической кинетики (упрощённая)
- Тест алгоритмов управления хаосом
- Бенчмарк для методов расчёта ляпуновских показателей
