# Аттрактор Хальворсена

## Обзор

**Аттрактор Хальворсена** — циклически-симметричная хаотическая система.
Все три уравнения инвариантны относительно циклической перестановки
переменных (x → y → z → x). Из-за этого аттрактор имеет **ось симметрии
третьего порядка**.

Внешне напоминает трёхлопастную «звезду» — три взаимно-перпендикулярных
«крыла», соединённых в центре.

## Уравнения

```text
ẋ = −ax − 4y − 4z − y²
ẏ = −ay − 4z − 4x − z²
ż = −az − 4x − 4y − x²
```

## Параметры

| Параметр | Диапазон | По умолчанию | Смысл |
|---|---|---|---|
| **a** | 1.0–3.0 | 1.89 | Линейная диссипация |

## Что смотреть в ChaosLab

### Attractor

Трёхлучевой аттрактор. При вращении камерой видно, что все три «крыла»
**эквивалентны** — это следствие симметрии.

**Рекомендации:**
- Палитра: Fire или Inferno
- Iterations: 3M
- Camera: Yaw = 0.4, Pitch = −0.3, Zoom = 55

### Bifurcation Diagram (a)

При a < 1.5 — устойчивая точка. При a = 1.89 — классический хаос.
При a > 2.5 — переход к периодическому режиму.

## Математическое значение

Хальворсен — один из **эталонных примеров симметричного хаоса**.
Изучается в курсах теории динамических систем как пример применения
теории групп к анализу хаотических систем.

## Применения

- **Симметрийный анализ хаоса**
- **Компьютерная графика** — красивая декоративная форма
- **Физика** — модель трёх связанных осцилляторов
