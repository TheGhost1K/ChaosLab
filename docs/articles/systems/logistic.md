# Логистическое отображение

## Обзор

**Логистическое отображение** — простейшая модель динамики популяции,
демонстрирующая переход к хаосу через каскад удвоения периода. Один из
главных примеров в курсе нелинейной динамики.

## Уравнение

```text
xₙ₊₁ = r·xₙ(1 − xₙ)
```

## Параметр

| Параметр | Диапазон | По умолчанию |
|----------|----------|--------------|
| **r** | 0–4 | 3.9 |

## Режимы в зависимости от r

| Диапазон r | Режим |
|-----------|-------|
| 0 – 1 | Вымирание (x → 0) |
| 1 – 3 | Устойчивая точка |
| 3 – 3.449 | 2-цикл |
| 3.449 – 3.544 | 4-цикл |
| 3.544 – 3.569 | 8, 16, 32… |
| **r∞ ≈ 3.5699** | **Точка накопления Фейгенбаума** |
| 3.57 – 4 | Хаос с окнами периодичности |
| 4 | Полный хаос |

## Универсальность Фейгенбаума

Отношения длин интервалов между бифуркациями сходятся к константе:

```text
δ = 4.669201609...
```

Это **универсальная константа**: она одинакова для всех отображений с
квадратичным максимумом.

## Что смотреть в ChaosLab

### Attractor (x_n, x_{n+1})

Парабола y = r·x(1−x). Точки показывают итерации.

### Bifurcation (r)

Классическое «дерево Фейгенбаума» — каскад удвоений, хаотические
области с периодическими окнами.

### Cobweb

Паутина итераций: прямая y = x и ломаная, показывающая итерации.
Идеальный режим для понимания динамики отображения.

## Ожидаемые характеристики

При r = 4:

- λ₁ = log 2 ≈ **0.693**
- D₂ = 1.0
- Топологически сопряжено со сдвигом Бернулли

## Историческая справка

Модель использовалась Робертом Мэем (1976) для демонстрации того, что
простые детерминированные системы могут давать хаотическую динамику.
Работа Мэя стала поворотным моментом в применении теории хаоса
к биологии.

## Применения

- Модели популяционной динамики
- Генераторы псевдослучайных чисел
- Обучение теории хаоса
