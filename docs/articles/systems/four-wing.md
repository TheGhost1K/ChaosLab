# Четырёхкрылый аттрактор

## Обзор

**Four-Wing аттрактор** — редкий пример хаотической системы с **четырьмя
симметричными «крыльями»**. Большинство хаотических потоков имеют 1–2
крыла (Лоренц, Chen, Rössler).

Четырёхкрылые системы важны для **классификации топологии аттракторов**
и для понимания того, сколько «структуры» может возникнуть из простых
квадратичных уравнений.

## Уравнения

```text
ẋ = ax + yz
ẏ = bx + cy − xz
ż = −z − xy
```

## Параметры

| Параметр | Диапазон | По умолчанию | Смысл |
|---|---|---|---|
| **a** | 0.1–0.4 | 0.2 | Линейное растяжение x |
| **b** | 0.001–0.05 | 0.01 | Слабая связь x в ẏ |
| **c** | −0.7…−0.2 | −0.4 | Отрицательная диссипация y |

## Что смотреть в ChaosLab

### Attractor

Четыре «крыла», симметрично расположенные относительно центра. Из-за
сильной нелинейности траектория быстро перескакивает между ними.

**Рекомендации:**
- Палитра: Plasma
- Iterations: 10M (крылья заполняются медленно)
- Camera: Zoom = 40

## Почему это важно

**Классификационная задача.** Одна из открытых задач теории хаоса —
сколько различных топологических типов аттракторов может породить
система из 3 квадратичных уравнений. Four-Wing — один из немногих
известных четырёхкрылых примеров.
