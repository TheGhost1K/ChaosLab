# Отображение Икеды

## Обзор

**Отображение Икеды (1979)** — модель прохождения света через нелинейный
оптический резонатор с задержкой. Возникает при изучении **оптической
бистабильности**.

При u = 0.918 даёт многослойный странный аттрактор с плавными
спиральными структурами.

## Уравнения

```text
t = 0.4 − 6/(1 + xₙ² + yₙ²)
xₙ₊₁ = 1 + u(xₙcos t − yₙ sin t)
yₙ₊₁ = u(xₙ sin t + yₙ cos t)
```

## Параметр

| Параметр | Диапазон | По умолчанию | Смысл |
|---|---|---|---|
| **u** | 0.7–1.0 | 0.918 | Коэффициент потерь в резонаторе |

## Что смотреть в ChaosLab

### Attractor

Спиральная структура с несколькими оборотами. При увеличении u слои
аттрактора становятся тоньше и многочисленнее.

**Рекомендации:**
- Палитра: Sunset или Fire
- Iterations: 500K
- Camera: Zoom = 130

### Bifurcation Diagram (u)

При u < 0.85 — устойчивый цикл. При u ≈ 0.9 — первая бифуркация.
При u > 0.95 — развитый хаос.

## Физика модели

**Оптический резонатор** — зеркальная полость, внутри которой
циркулирует свет. При наличии **нелинейной среды** (например, среды
с показателем преломления, зависящим от интенсивности) система
проявляет **бистабильность** и **хаос**.

Модель Икеды — простейшее описание такой системы.

## Применения

- **Оптика** — динамика лазеров с обратной связью
- **Теория хаоса** — пример отображения из физики
- **Синхронизация** — хаотические оптические коммуникации
