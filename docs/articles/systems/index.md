# Системы

ChaosLab содержит **33 вычислительные модели** в трёх категориях.

| Категория | Кол-во | Примеры |
|-----------|--------|---------|
| Потоки (Flow) | 20 | Lorenz, Rössler, Chua, FPUT-β, Hénon-Heiles, Lorenz-96 |
| Отображения (Map) | 12 | Logistic, Hénon, Ikeda, Arnold Cat, Circle |
| Поля (Field) | 1 | Gray-Scott |

## Как выбрать систему

**Первый запуск** — Lorenz или Rössler: узнаваемые аттракторы, много
литературы.

**Переход к хаосу** — Logistic (диаграмма Фейгенбаума) или Circle Map
(языки Арнольда).

**Красивые визуализации** — Aizawa, Thomas, De Jong, Clifford, Chua.

**Проверка методов анализа** — Lorenz (λ₁ ≈ 0.906, D₂ ≈ 2.06),
Hénon (λ₁ ≈ 0.419, D₂ ≈ 1.26), Arnold Cat (λ₁ = log φ² ≈ 0.962).

**Высокоразмерный хаос** — Lorenz-96 с N = 8 или 16.

**Самоорганизация** — Gray-Scott.

**Физические приложения** — Chua (электроника), Rikitake (геофизика),
Newton-Leipnik (механика твёрдого тела).

**Гамильтоновы системы** — Hénon-Heiles: сохраняет энергию, поддерживает
симплектический интегратор Verlet.

**Нелинейные решётки** — FPUT-β (эксперимент Ферми–Паста–Улама),
Coupled Pendulums (цепочка маятников).

**Мультистабильность** — Newton-Leipnik (два аттрактора).

**Синхронизация** — Circle Map (языки Арнольда).

## Общее про все системы

Каждая система:

- Реализует `ISimulation` — единый контракт для UI.
- Имеет параметры по умолчанию, дающие хаос (λ₁ > 0).
- Поддерживает аналитический JVP (в 2 раза быстрее численного).
- Имеет **описание каждого параметра** для тултипа.
- Проверена на известное значение λ₁ (см. `tests/`).
