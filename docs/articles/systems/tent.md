# Тент-отображение

## Обзор

**Тент-отображение** — кусочно-линейное хаотическое отображение.
Название происходит от формы графика функции — остроконечный «тент».

Простота отображения (линейность на каждом отрезке) делает его
удобным для аналитического исследования: многие характеристики
вычисляются точно.

## Уравнение

```text
xₙ₊₁ = μ·xₙ       (xₙ < 0.5)
xₙ₊₁ = μ(1 − xₙ)  (xₙ ≥ 0.5)
```

## Параметр

| Параметр | Диапазон | По умолчанию | Смысл |
|---|---|---|---|
| **μ** | 1.0–2.0 | 1.99 | Наклон тента |

### Cobweb

Тент-отображение — один из лучших примеров для cobweb-диаграммы.
График функции — идеальный тент, и итерации образуют чёткий узор.

## Ожидаемые характеристики

При μ = 2:

| Метрика | Значение |
|---|---|
| λ₁ | **log 2 ≈ 0.693** |
| D₂ | 1.0 |
| Топологическая энтропия | log 2 |

## Связь с логистикой

**Теорема:** при μ = 2 тент-отображение **топологически сопряжено**
с логистическим отображением при r = 4. Существует непрерывная
монотонная замена переменных, переводящая одно в другое.

**Следствие:** все инварианты (λ₁, энтропия, D₂) совпадают. Для
логистики аналитические результаты получить сложно, а для тента —
легко. Поэтому тент используется как «модельный» пример.

## Аналитические результаты

Для тента можно строго доказать:

- λ₁ = log μ (при μ > 1)
- Инвариантная мера — равномерная на [0, 1]
- Система эргодична
- Топологическая энтропия = log μ

## Применения

- **Теория хаоса** — эталон для аналитических вычислений
- **Криптография** — генератор псевдослучайных чисел
- **Педагогика** — проще логистики для понимания
