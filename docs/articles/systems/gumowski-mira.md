# Отображение Гумовского–Миры

## Обзор

**Gumowski-Mira map (1973)** — квази-консервативное отображение
с красивыми симметричными структурами, напоминающими «морские звёзды»
или «снежинки».

При μ ≈ 0.01 отображение близко к **консервативному** (сохраняет
площадь), что даёт структуры, похожие на KAM-торы в гамильтоновых
системах.

## Уравнения

```text
f(x) = ax + 2(1−a)x² / (1 + x²)
xₙ₊₁ = b·yₙ + f(xₙ)
yₙ₊₁ = −xₙ + f(xₙ)
```

## Параметры

| Параметр | Диапазон | По умолчанию | Смысл |
|---|---|---|---|
| **μ** | −1.0…1.0 | 0.01 | Оставлен для совместимости |
| **a** | −1.0…1.0 | −0.31 | Квадратичный коэффициент |
| **b** | 0.5–1.5 | 1.0 | Коэффициент в x' |

## Что смотреть в ChaosLab

### Attractor

Симметричные структуры с несколькими «лепестками». При b = 1 и
a = −0.31 получается классическая «морская звезда».

**Рекомендации:**
- Палитра: Emerald
- Iterations: 500K
- Camera: Zoom = 130

### Bifurcation Diagram (a)

Варьируйте a от −1.0 до 1.0. Картина меняется от простых циклов
до сложных квазипериодических структур.

## Особенность

Gumowski-Mira — пример **«квазипериодического»** отображения с
плавным переходом к хаосу. При μ = 0 отображение строго
консервативно; при μ ≠ 0 появляется слабая диссипация, и структура
постепенно разрушается.

## Применения

- **Компьютерная графика** — генерация орнаментов
- **Математика** — пример 2D отображения с богатой структурой
- **Физика плазмы** — моделирование удержания частиц
