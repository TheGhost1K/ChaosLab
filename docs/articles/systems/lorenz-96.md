# Lorenz-96

## Обзор

**Lorenz-96** — обобщение системы Лоренца на N-мерное фазовое пространство.
Предложена Эдвардом Лоренцом в 1996 году как «игрушечная модель»
атмосферной динамики средних широт.

Широко используется в **data assimilation** и **machine learning для
динамических систем** как эталон высокоразмерного хаоса.

## Уравнения

```text
ẋⱼ = (x_{j+1} − x_{j−2})·x_{j−1} − xⱼ + F
```

для j = 0, 1, ..., N−1, с периодическими граничными условиями
(индексы по модулю N).

## Параметры

| Параметр | Смысл | Диапазон | По умолчанию |
|----------|-------|----------|--------------|
| **F** | Внешний форсинг | 4–20 | 8 |
| **N** | Размерность модели | 4–32 | 8 |

## Режимы в зависимости от F

- **F < 1** — устойчивое равновесие
- **1 < F < 5** — периодические орбиты
- **5 < F < 8** — переход к хаосу через последовательность бифуркаций
- **F > 8** — **полностью развитый хаос**

При F = 8 система имеет **N положительных показателей Ляпунова** —
это признак гиперхаоса.

## Особенности в ChaosLab

### Проекция на 3D

Lorenz-96 живёт в N-мерном пространстве. Для визуализации ChaosLab
проецирует первые три компоненты (x₀, x₁, x₂). Это **не настоящий
аттрактор** системы, но даёт представление о её динамике.

### JVP эксплуатирует разреженность

Якобиан системы имеет только **4 ненулевых элемента на строку**.
Аналитический `JacobianVectorProduct` использует это и даёт **×7 ускорение**
по сравнению с численной аппроксимацией:

| N | Численно | Аналитически |
|---|----------|--------------|
| 8 | 240 ops | 64 ops |
| 16 | 960 ops | 128 ops |
| 32 | 3840 ops | 256 ops |

### Спектр Ляпунова

При F = 8, N = 8: **5 из 8 показателей положительны**. Спектр выглядит
примерно так:

```text
λ₁ ≈ +1.50
λ₂ ≈ +0.80
λ₃ ≈ +0.30
λ₄ ≈ +0.15
λ₅ ≈ +0.05
λ₆ ≈ −0.20
λ₇ ≈ −1.20
λ₈ ≈ −14.0
```

Сумма всех λᵢ = −N (по теореме о дивергенции).

## Что смотреть

### Attractor (проекция)

Даёт «запутанный» 3D-объект без выраженной структуры — типичный
высокоразмерный хаос.

### Спектр Ляпунова

Нажмите **λ Спектр** — увидите 5 положительных показателей.
Это наглядно демонстрирует, что хаос не требует 3D — он может быть
многомерным.

### Карта Ляпунова (F, N)

Не реализована в UI, потому что N — целочисленный параметр. Используйте
**Bifurcation** по F для N = 8.

## Применения

- **Data assimilation** — тесты алгоритмов (EnKF, 4D-Var)
- **Weather forecasting** — бенчмарк для ML-моделей
- **Reservoir computing** — обучение на хаотических рядах
- **Lyapunov spectrum** — проверка численных методов
