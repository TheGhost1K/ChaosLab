# Отображение кота Арнольда

## Обзор

**Arnold's cat map** (1967) — знаменитое сохраняющее площадь отображение
тора. Название происходит от картинки кота, которую Владимир Арнольд
использовал в своих лекциях для демонстрации «перемешивания».

Если нарисовать кота на торе и итеративно применить отображение, картинка
деформируется и «размазывается», пока не превратится в однородную
структуру. Но при достаточно большом числе итераций кот **восстанавливается**
(из-за сохранения меры).

## Уравнения

```text
x_{n+1} = xₙ + yₙ          (mod 1)
y_{n+1} = xₙ + (1+k)·yₙ    (mod 1)
```

Матрица отображения:

```text
M = [[1, 1], [1, 1+k]]
```

## Параметр

| Параметр | Диапазон | По умолчанию | Смысл |
|---|---|---|---|
| **k** | 1–5 | 1 | Форма матрицы |

## Что смотреть в ChaosLab

### Attractor

Плотная структура, заполняющая весь тор. Из-за сильного перемешивания
аттрактор выглядит как «шум» — но это детерминированная система.

**Рекомендации:**
- Палитра: Rainbow
- Iterations: 500K
- Camera: Zoom ≈ 800, CenterX = CenterY = 0.5

### Bifurcation Diagram (k)

От k = 1 до k = 5 — всё хаос. Отображение кусочно-линейное, поэтому
не имеет классического каскада бифуркаций.

### Lyapunov Map

Матрица постоянна, поэтому карта λ не зависит от начальных условий.
Для k = 1:

```text
λ₁ = log((3 + √5)/2) ≈ +0.9624
λ₂ = −λ₁  (сохранение площади)
```

## Ожидаемые характеристики

Для k = 1:

| Метрика | Значение |
|---|---|
| λ₁ | +0.9624 = log(φ²) |
| λ₂ | −0.9624 |
| Σλ | 0 (сохранение площади) |
| h_KS | 0.9624 |
| D₂ | 2.0 (заполняет весь тор) |

## Математическое значение

Arnold's cat map — **канонический пример**:

- **Эргодической системы** — траектория равномерно заполняет тор
- **Перемешивающей системы** — корреляции убывают экспоненциально
- **Гиперболической системы** — все направления растягиваются/сжимаются
- **Гамильтоновой системы** — сохраняет площадь

Это одна из немногих систем, где **все** инварианты вычисляются
аналитически.

## Применения

- **Теория эргодичности** — эталон хаоса
- **Криптография** — Arnold cat map используется в шифровании изображений
- **Сжатие данных** — теория «перемешивающих» отображений
- **Квантовые вычисления** — модель хаотической динамики

## История

Владимир Арнольд использовал эту карту в лекциях 1960-х годов для
иллюстрации эргодической теории. Рисунок кота стал настолько популярным,
что его воспроизводят в десятках учебников.
