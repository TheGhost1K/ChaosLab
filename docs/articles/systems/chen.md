# Система Чена

## Обзор

**Система Чена** (Guanrong Chen, 1999) — «двойник» Лоренца: похожа по
форме, но **не топологически эквивалентна** ему. Аттрактор Chen нельзя
получить непрерывной деформацией аттрактора Lorenz.

## Уравнения

```text
ẋ = a(y − x)
ẏ = (c − a)x − xz + cy
ż = xy − bz
```

## Параметры

| Параметр | Диапазон | По умолчанию |
|----------|----------|--------------|
| **a** | 20–45 | 35 |
| **b** | 1–6 | 3 |
| **c** | 20–32 | 28 |

## Отличия от Лоренца

При a = 35, b = 3, c = 28:

- **λ₁ ≈ 2.03** — почти вдвое быстрее Лоренца
- Размерность аттрактора D₂ ≈ 2.1 — чуть выше
- Аттрактор **более «плотный»** и требует больше итераций для
  визуализации
- В отличие от Лоренца, не имеет «дырок» в структуре

## Что смотреть

### Attractor

Двойной вихрь, но с более резкими границами и меньшим «размахом».
Траектория быстрее проходит между фокусами.

### Спектр Ляпунова

λ₁ ≈ +2.03 — обратите внимание, что это заметно больше лоренцевского
0.906. Система «более хаотична».

## Ожидаемые характеристики

| Величина | Значение |
|----------|----------|
| λ₁ | +2.03 |
| λ₂ | 0 |
| λ₃ | −12.0 |
| Σλᵢ | −(a + b + 1) = −39 |
| D₂ | ~2.1 |

## Применения

- Тест алгоритмов синхронизации хаоса
- Криптография (хаотические генераторы)
- Проверка методов различения «похожих» аттракторов
