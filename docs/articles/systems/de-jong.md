# Отображение Де Йонга

## Обзор

**Отображение Де Йонга** — декоративное хаотическое отображение,
опубликованное Питером де Йонгом в 1987 году. Даёт **слоистые структуры**
с плавными переходами.

Как и Clifford, не имеет физического происхождения — используется
для генерации красивых фракталов.

## Уравнения

```text
xₙ₊₁ = sin(ayₙ) − cos(bxₙ)
yₙ₊₁ = sin(cxₙ) − cos(dyₙ)
```

## Параметры

| Параметр | Диапазон | По умолчанию | Смысл |
|---|---|---|---|
| **a** | −3…3 | 1.4 | Частота sin по y в x' |
| **b** | −3…3 | −2.3 | Частота cos по x в x' |
| **c** | −3…3 | 2.4 | Частота sin по x в y' |
| **d** | −3…3 | −2.1 | Частота cos по y в y' |

## Что смотреть в ChaosLab

### Attractor

Тонкие «ленты», спиралями закрученные вокруг центра. При увеличении
видны области с плавными переходами и резкими границами.

**Рекомендации:**
- Палитра: Ice или Emerald
- Iterations: 500K
- Camera: Zoom = 180

### Vector field overlay

Полезен для понимания, как работает отображение. Особенно интересно
смотреть в точках, где вектор направления резко меняется.

## Ожидаемые характеристики

|---|---|

| D₂ | ≈ 1.9 |
| Область | x, y ∈ [−2, 2] |

## Сравнение с Clifford

| Свойство | Clifford | De Jong |
|---|---|---|
| Формула | sin + c·cos | sin − cos |
| Структура | «Цветочная» | «Слоистая» |
| Рекомендуемые параметры | a = −1.4 | a = 1.4 |

Оба отображения в ChaosLab — для визуального удовольствия.
