# Термостат Нозе–Хувера

## Обзор

**Термостат Нозе–Хувера (1985)** — детерминированная модель термостата
для молекулярной динамики. В отличие от стохастических методов
(Ланжевен, Андерсен), здесь температура поддерживается **детерминированно**
через дополнительную динамическую переменную.

Для некоторых параметров система хаотична, что делает её интересным
примером детерминированного термостата.

## Уравнения

```text
ẋ = y
ẏ = −x − yz
ż = y² − a
```

## Параметры

| Параметр | Диапазон | По умолчанию | Смысл |
|---|---|---|---|
| **a** | 0.5–3.0 | 1.5 | Целевая кинетическая энергия |

## Что смотреть в ChaosLab

### Attractor

Спиральная структура вокруг начала координат. При a = 1.5 аттрактор
заполняет характерную «линзу» в фазовом пространстве.

**Рекомендации:**
- Палитра: Ice
- Iterations: 3M
- Camera: Zoom = 45

### Bifurcation Diagram (a)

Варьируйте a от 0.5 до 3.0. При малых a — устойчивая точка. При a ≈ 1.0 —
предельный цикл. При a > 1.4 — хаос.

## Ожидаемые характеристики

Для a = 1.5:

| Метрика | Значение |
|---|---|
| λ₁ | ≈ +0.01 |
| D₂ | ≈ 2.0 |
| Характер | Гиперхаос при некоторых a |

## Физический смысл

В молекулярной динамике термостат Нозе–Хувера эволюционирует систему
вместе с дополнительной переменной z, играющей роль «трения». Эта
переменная регулирует кинетическую энергию так, чтобы средняя
температура совпадала с целевой.

**Преимущества над стохастическими термостатами:**
- Детерминированность — нет случайности
- Сохранение энергии в расширенной системе
- Правильная каноническая статистика (при выполнении эргодичности)

## Применения

- **Молекулярная динамика** — моделирование жидкостей
- **Физика плазмы** — удержание частиц
- **Теория хаоса** — пример 1D-консервативной системы с хаосом
