# Начало работы

## Установка

### Windows

Скачайте последний релиз с [GitHub Releases](https://github.com/TheGhost1K/ChaosLab/releases)
и распакуйте в любую папку. Запустите `ChaosLab.exe`.

### Сборка из исходников

```bash
git clone https://github.com/TheGhost1K/ChaosLab.git
cd ChaosLab
dotnet build ChaosLab.slnx -c Release
```

Требуется **.NET 10 SDK** и **Windows 10/11**.

## Что умеет ChaosLab

- **33 вычислительные модели** — потоки (Lorenz, Chua, Hénon-Heiles, …),
  отображения (Hénon, Arnold Cat, Circle, …), реакционно-диффузионные поля
- **10 режимов отображения** — аттрактор, бифуркации, карта Ляпунова,
  cobweb, спектр, return map, FNN+MI, мультифрактал, multiscale entropy,
  живой след (Trail)
- **24 метода анализа** — Ляпунов, D₂, KS-энтропия, Higuchi FD, энтропии,
  LZ-сложность, RQA, символическая динамика, резонансы, предсказуемость

### Левая панель

- **Система** — выпадающий список 33 моделей
- **Режим** — 10 режимов отображения (см. ниже)
- **Параметры** — слайдеры, **при наведении мыши показывают
  физический смысл**
- **Рендер** — Iterations, dt, Gamma, палитра
- **Интеграторы** — чекбоксы Verlet (симплектический) и Adaptive RK45
- **Vector field overlay** — слой стрелок для 2D отображений
- **Камера** — Yaw, Pitch, Zoom
- **Действия** — Render, Clear, Reset Cam, Animate, PNG

### Центр

Холст с изображением. Размер **автоматически подстраивается** под окно,
включая DPI-масштаб (125%, 150%). HUD в правом верхнем углу показывает
текущий режим, число точек, время рендера и разрешение.

### Правая панель

- **Анализ** — результаты всех методов анализа
- **Справка** — глоссарий, горячие клавиши, советы

## Режимы отображения

| Режим | Что показывает | Когда использовать |
|---|---|---|
| **Attractor** | Фазовый портрет | Увидеть структуру аттрактора |
| **Bifurcation** | Диаграмма по параметру | Найти переход к хаосу |
| **Lyapunov Map** | Тепловая карта λ₁ по двум параметрам | Границы хаоса в плоскости параметров |
| **Cobweb** | Паутина итераций | Понимание 1D-отображений |
| **Power Spectrum** | Спектр через FFT | Различение периодики и хаоса |
| **Return Map** | xₙ → xₙ₊₁ | Редукция потока к 1D |
| **FNN + MI** | Диагностика вложения | Правильный выбор delay и m |
| **Multifractal** | Спектр D_q | Различение моно- и мультифрактала |
| **Multiscale Entropy** | SampEn(τ) | Различение «сложного» хаоса и белого шума |
| **Trail** | Живой след траектории | Динамика вместо структуры |

## Первый аттрактор за 30 секунд

1. Открывается аттрактор Лоренца по умолчанию.
2. Нажмите **Render** (или `Ctrl + R`).
3. Через 1–2 секунды увидите классический «двойной вихрь».

**Совет:** наведите мышь на слайдер **σ** — увидите
«Число Прандтля: отношение вязкости к температуропроводности».

## Что попробовать в первую очередь

### Классика — двойной свиток Chua

1. Система: **Chua's Circuit**
2. Палитра: **Plasma**
3. Iterations: 5M
4. Render

Это реальная электронная схема, впервые показавшая хаос в железе.

### Переход к хаосу — диаграмма Фейгенбаума

1. Система: **Logistic**
2. Режим: **Bifurcation Diagram**
3. Увидите классическое дерево удвоения периода

### Карта Ляпунова — где живёт хаос

1. Система: **Lorenz**
2. Режим: **Lyapunov Map**
3. Ось X: ρ `[1, 60]`, ось Y: σ `[1, 30]`
4. **Белая линия** — граница λ = 0

**Правый клик** по любой точке карты → переход в Attractor с этими
параметрами.

### Живой след

1. Любая система
2. Режим: **Trail**
3. Кнопка **Animate** (`● Animate`) → переключится на `■ Stop`
4. Увидите, как траектория «прорисовывает» аттрактор в реальном времени

## Интеграторы

ChaosLab поддерживает **три интегратора** для потоков:

### RK4 (по умолчанию)

Классический Рунге–Кутта 4-го порядка. Быстрый, универсальный.
Подходит для большинства систем.

### Verlet (симплектический)

Доступен для **гамильтоновых** систем (Hénon-Heiles, FPUT-β,
Coupled Pendulums). Включается чекбоксом **Use Verlet integrator**.

- **Сохраняет энергию** точно
- Не «уползает» при миллионах шагов
- В 4 раза быстрее RK4 на один шаг

**Попробуйте:** откройте **Hénon-Heiles** → включите Verlet →
отрисуйте 10M точек → сравните с RK4. У RK4 траектория сжимается,
у Verlet — остаётся на месте.

### Adaptive RK45

Dormand-Prince 5-го порядка с автоматическим управлением шагом.
Включается чекбоксом **Use Adaptive RK45**.

Слайдер **RK45 Tolerance** управляет точностью:

- `1e-6` — высокая точность, медленно
- `1e-4` — баланс (по умолчанию)
- `1e-3` — быстро, для визуализации

Используйте для систем с широким спектром временных масштабов.

## Vector field overlay

Для **2D дискретных отображений** (Hénon, Clifford, De Jong, Tinkerbell)
доступен чекбокс **Vector field overlay**. Он показывает стрелки,
отображающие направление потока `f(x, y) − (x, y)` поверх аттрактора.

**Когда полезно:** анализ топологии — увидеть, куда «тянет» систему
в каждой точке фазового пространства.

## Управление мышью

- **ЛКМ + перетаскивание** — вращение камеры (3D) или панорамирование (2D)
- **Колесо мыши** — приближение/отдаление
- **Правый клик по карте Ляпунова** — переход в режим Attractor
  с параметрами точки клика
- **Наведение на слайдер** — тултип с описанием параметра

## Горячие клавиши

| Клавиша | Действие |
|---|---|
| `Ctrl + S` | Сохранить текущее изображение в PNG |
| `Ctrl + R` | Сбросить камеру и перерисовать |
| `Esc` | Отменить текущий анализ |

## Живое изменение параметров

Слайдеры параметров подключены к рендеру: пока вы двигаете ползунок,
аттрактор перестраивается в фоне. UI не блокируется — это сделано
через асинхронный планировщик с **коалесцированием** запросов.

**Производительность:** при быстром движении слайдера запускается только
последний запрос, промежуточные отбрасываются. Даже на медленных
системах UI отзывчив.

## Кнопка Animate

**Animate** включает непрерывный рендер (~60 FPS):

- В режиме **Attractor** — накапливает всё больше точек
- В режиме **Trail** — рисует живой след траектории
- В других режимах — обновляет кадр (не всегда осмысленно)

Нажмите ещё раз, чтобы остановить.

## Кнопка «Запустить всё»

Последовательно запускает **все** методы анализа. Прогресс показывается
внизу правой панели: `[7/16] DFA…`.

Порядок: от быстрых (Lyapunov, Entropy) к медленным
(Poincaré, Basin entropy). Полный прогон — 20–40 секунд для типичной
системы.

**Прервать:** кнопка **Отмена**.

## Сохранение результата

- **PNG** или `Ctrl + S` — сохранить текущий холст
- Имя файла содержит имя системы и timestamp:
  `chaos_Lorenz_20261011_143022.png`
- Разрешение — размер текущего холста (2048×1152 при FullHD)

## Полезные советы

1. **Для бифуркаций** выбирайте *интересный* параметр. Для Лоренца — ρ,
   не β. Для Chua — α, не m₀.

2. **Для карты Ляпунова** убедитесь, что система имеет ≥ 2 параметра.

3. **Для Trail** включите Animate — без него будет один статичный кадр.

4. **Для Hénon-Heiles** включите Verlet — увидите разницу в сохранении
   энергии.

5. **Медленный рендер?** Уменьшите Iterations или разрешение окна.

6. **Не работает кнопка?** Наведите — тултип объясняет, для каких систем
   она доступна.

## Что если что-то пошло не так

**Программа зависла при анализе** — нажмите **Отмена** в правом нижнем
углу. Все методы проверяют токен отмены каждые несколько тысяч шагов.

**Аттрактор выглядит не так, как на картинках** — возможно, параметры
отличаются. Сбросьте: **Clear** → смена системы → обратно → Render.

**Ошибка «для потока требуется Rk4Scratch»** — это внутренняя ошибка,
не должна появляться. Если видите — сообщите через GitHub Issues
с указанием системы и режима.
