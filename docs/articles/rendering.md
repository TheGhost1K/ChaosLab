# Режимы отображения

ChaosLab предлагает 9 режимов отображения. Переключение — через комбобокс
**РЕЖИМ** в левой панели.

## Attractor

Основной режим. Строит фазовый портрет аттрактора.

Как работает:

- Итеративно продвигает систему
- Каждую точку проецирует на холст через ортографическую камеру
- Накопление в буфер плотности (ushort)
- Лог-масштабирование → палитра

Параметры:

- **Iterations** — сколько шагов отрисовать (1K–100M)
- **dt** — шаг интегрирования (для потоков)
- **Gamma** — нелинейная коррекция яркости

Когда использовать: всегда, когда хочется увидеть структуру аттрактора.

## Bifurcation

Диаграмма удвоения периода. Ось X — параметр, ось Y — значения координаты.

Для отображений: строит последовательность xₙ для каждого r.

Для потоков: использует метод локальных максимумов x(t) — эквивалент
сечения Пуанкаре.

Когда использовать: чтобы увидеть переход к хаосу через каскад
бифуркаций Фейгенбаума.

## Lyapunov Map

Тепловая карта старшего показателя Ляпунова по двум параметрам.

Как работает:

- Для каждой точки (p₁, p₂) считает λ₁ вариационным методом
- Синяя половина палитры — λ < 0 (устойчивость)
- Оранжевая половина — λ > 0 (хаос)
- Белая линия — граница λ = 0

Интерактив:

- ЛКМ по карте — вращение/панорамирование
- ПКМ по карте — перейти в Attractor с этими параметрами

Производительность: прогрессивный рендер — превью 256×256 за 0.3 с,
полный холст через 1–2 с.

Когда использовать: чтобы найти «острова» хаоса и периодичности в
пространстве параметров.

## Cobweb

Паутина итераций для 1D-отображений.

Строит:

- Диагональ y = x
- График y = f(x)
- Ломаную итераций x₀ → f(x₀) → f(f(x₀)) → ...

Когда использовать: для логистики, тента, Гаусса — видно, как именно
система «прыгает» по параболе.

## Power Spectrum

Спектральная плотность через FFT с окном Ханна.

Лог-график амплитуды по частоте:

- Дискретные пики — периодика или квазипериодика
- Широкополосный спектр — хаос
- Степенной закон — 1/f шум

Когда использовать: для проверки природы динамики (Langford — пики,
Lorenz — шум).

## Return Map

Отображение xₙ → xₙ₊₁ по локальным максимумам координаты.

Для Лоренца даёт тентоподобную кривую — «квази-логистику».

Когда использовать: для понимания топологии аттрактора — часто
позволяет свести хаотический поток к одномерному отображению.

## FNN + MI

Диагностика вложения (Fraser-Swinney, Kennel et al.):

- Mutual Information MI(τ) — первый минимум даёт оптимальный delay
- False Nearest Neighbors FNN(m) — доля ложных соседей; при m,
  где кривая падает до 0, вложение корректно

Когда использовать: для проверки, что ваш delay-embedding выбран
правильно (влияет на D₂, RQA, фракталы).

## Multifractal

Обобщённые размерности D_q:

```text
D_q = (1/(q−1)) · lim_{r→0} log Σ pᵢ^q / log r
```

- D₀ — box-counting
- D₁ — информационная
- D₂ — корреляционная
- D₋∞ … D₊∞ — спектр мультифрактала

Если D_q зависит от q — аттрактор мультифрактален (типично для хаоса).

## Trail

Режим **живого следа**: одна траектория с затухающим хвостом. Показывает
**динамику**, а не структуру аттрактора.

- **Хвост** — N точек с линейным затуханием яркости
- **Голова** — яркий акцентный цвет
- **Анимация** — включается кнопкой **Animate** (или автоматически)

**Когда использовать:** для презентаций и интуитивного понимания
того, что аттрактор — это **поток**, а не статичная структура.

## Vector field overlay

Слой стрелок, показывающий направление потока `f(x, y) − (x, y)`
поверх аттрактора. Доступен для **2D дискретных отображений**
(Hénon, Clifford, De Jong, Tinkerbell).

Включается чекбоксом **Vector field overlay** в блоке РЕНДЕР.

**Когда использовать:** для анализа топологии — увидеть, куда «тянет»
поток в каждой точке, одновременно со структурой аттрактора.
