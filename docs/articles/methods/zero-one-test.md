# 0–1 тест хаоса

## Обзор

**0–1 тест Готтвальда–Мельбурна** (2004) — быстрый способ определить,
хаотична ли система, используя только скалярный временной ряд.

Преимущества:

- Не требует **reconstruction** фазового пространства
- Работает на **коротких** рядах (от 1000 точек)
- Устойчив к **шуму** и **нестационарности**

## Идея

Для каждого параметра c из диапазона (π/5, 4π/5) строится комплексное
преобразование:

```text
p_c(n) = Σⱼ₌₁ⁿ x(j) · cos(jc)
q_c(n) = Σⱼ₌₁ⁿ x(j) · sin(jc)
```

Затем считается среднее квадратичное смещение:

```text
M_c(n) = ⟨(p(j+n) − p(j))² + (q(j+n) − q(j))²⟩ⱼ
```

Для **хаоса** M_c(n) растёт линейно по n → корреляция с log(n) ≈ 1.
Для **регулярной динамики** M_c(n) ограничено → корреляция ≈ 0.

## Параметр K

ChaosLab использует **медиану** коэффициентов корреляции по 100 случайным c:

- **K ≈ 1** — хаос
- **K ≈ 0** — регулярная динамика
- **0.3 < K < 0.7** — переходная зона

## Что смотреть в ChaosLab

Раздел **СТАТИСТИКА**. Нажмите **0–1**.

Результат:

```text
K = 0.9987  (хаос)
```

## Ожидаемые значения

| Система | K |
|---|---|
| Устойчивая точка | ≈ 0 |
| Периодика (4-цикл) | ≈ 0.1 |
| Логистика (r = 4) | ≈ 1.0 |
| Lorenz | ≈ 0.95–1.0 |
| Белый шум | ≈ 1.0 |

**Важно:** 0–1 тест даёт K ≈ 1 **и** для хаоса, **и** для белого шума.
Он не различает **детерминированный** хаос и **случайный** шум. Для
этого нужны другие методы (SampEn, LZ-сложность).

## Параметры в ChaosLab

- **sampleCount = 4000** — длина ряда
- **nC = 100** — число случайных c
- **decimation** — прореживание ряда (см. ниже)

### Decimation

0–1 тесту нужен ряд с автокорреляцией на лаге 1 ≈ 0.7–0.9. Если данные
сильно over-sampled (маленький dt), K занижается. ChaosLab автоматически
использует `dt = 0.01, decimation = 20` для потоков — эффективный шаг
сэмплирования ≈ 0.2 t.e.

## Применения

- **Нейронауки** — детекция хаоса в ЭЭГ
- **Финансы** — проверка рыночных данных
- **Метеорология** — устойчивость климатических моделей
- **Гидродинамика** — переход к турбулентности
