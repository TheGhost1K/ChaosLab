# Multiscale Entropy

## Обзор

**Multiscale Entropy** (MSE) — метод анализа, при котором энтропия
считается не на одном временном масштабе, а на целом спектре масштабов.
Позволяет различить «сложные» системы (1/f шум, хаос) от «простых»
(белый шум, периодика), даже если их SampEn при τ = 1 похожи.

## Проблема обычной SampEn

Sample Entropy при τ = 1 (на «нативном» масштабе):

- **Белый шум**: SampEn высокое (система «непредсказуема»)
- **1/f шум**: SampEn высокое (тоже «непредсказуемо»)
- **Хаос**: SampEn среднее

По одной точке нельзя отличить **белый шум** (не является сложным) от
**1/f шума** (является сложным — есть корреляции на всех масштабах).
MSE решает это, глядя на **всю кривую** SampEn(τ).

## Coarse-graining

Для масштаба τ строится усреднённый ряд:

```text
yⱼ^(τ) = (1/τ) · Σᵢ₌₁ᵗ x_{(j−1)τ + i}
```

Проще говоря — берём окна длиной τ и заменяем их средним. Для τ = 1 ряд
не меняется, для τ = 2 — пары усредняются, для τ = 10 — десятки.

Затем на укороченном ряде считается SampEn(τ).

## Интерпретация MSE-кривой

**Три характерных формы:**

### 1. Монотонно убывает — белый шум

Белый шум некоррелирован: усреднение уничтожает его структуру, и SampEn
падает с ростом τ. Это «простая» система.

### 2. Плоская — 1/f шум

Розовый шум имеет корреляции на всех масштабах: при усреднении SampEn
остаётся постоянной. Это признак **сложности** — информация сохраняется
на всех масштабах.

### 3. Пик на промежуточных масштабах — детерминированный хаос

У хаотических систем есть характеристическое время (≈ 1/λ₁). На масштабах
близких к нему SampEn максимально. Это тоже признак **сложности**.

## Формальный критерий

ChaosLab использует эвристику:

- `SampEn(mid) > SampEn(τ=1)` и `SampEn(mid) > SampEn(max)` → пик
- `|SampEn(max) − SampEn(1)| < 0.15 · SampEn(1)` → плоская
- Иначе → убывает

## Параметры по умолчанию

- **maxScale = 12** — 12 масштабов
- **sampleCount = 3000** — длина исходного ряда
- m = 2, r = 0.2σ

**Почему 3000, а не 20000:** SampEn имеет сложность O(N²). При N = 20000
каждый масштаб — 4·10⁸ операций, весь MSE — секунды. При N = 3000 —
~10⁷ операций на масштаб, весь MSE за 0.5 секунды.

Погрешность SampEn при N = 3000 составляет ~2% — приемлемо для
визуальной оценки формы кривой.

## Что смотреть в ChaosLab

Два способа:

### По кнопке

1. Выберите систему.
2. Нажмите **Multiscale** в правой панели.
3. Увидите таблицу SampEn(τ) и классификацию формы.

### Графиком

1. В комбобоксе **РЕЖИМ** выберите **Multiscale Entropy**.
2. На холсте построится кривая SampEn(τ) от τ.

## Ожидаемые результаты

| Система | Форма | Характер |
|---------|-------|----------|
| Логистика (r=4) | Плоская | Сопряжена с 1/f |
| Лоренц | Слабый пик на τ ≈ 3–5 | Хаос |
| Hénon | Слабый пик | Хаос |
| Белый шум | Убывает | Случайность |
| Периодика | Убывает | Регулярность |

## Ограничения

- Требует **стационарности** ряда. Для нестационарных систем результат
  искажён.
- **Длина ряда должна быть ≥ 10 · maxScale**, иначе короткие масштабы
  будут посчитаны по малому числу точек.
- **r = 0.2σ фиксировано**. Для систем с очень узким или широким
  распределением нужна настройка.

## Применения

- Физиология: вариабельность сердечного ритма (HRV)
- Нейронауки: анализ ЭЭГ (различение эпилепсии от нормы)
- Финансы: различение случайного блуждания от тренда
- Климат: различение природной изменчивости от антропогенного тренда
