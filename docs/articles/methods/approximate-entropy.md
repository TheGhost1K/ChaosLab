# Approximate Entropy (ApEn)

## Обзор

**Approximate Entropy** (Pincus, 1991) — мера непредсказуемости временного
ряда. **Предшественник** Sample Entropy: использует ту же идею подсчёта
совпадающих паттернов, но с двумя отличиями.

## Отличия от Sample Entropy

| Свойство | ApEn | SampEn |
|---|---|---|
| Самопарные совпадения (i = j) | Учитываются | **Исключены** |
| Нормализация | Φᵐ − Φᵐ⁺¹ | −log(A/B) |
| Смещение при малых N | Большое | Малое |
| Дисперсия | Высокая | Низкая |

По этим причинам SampEn почти вытеснил ApEn в современной литературе.
Но ApEn **исторически важен** и используется в старых работах — ChaosLab
включает его для совместимости и сравнения.

## Формула

```text
ApEn(m, r) = Φᵐ(r) − Φᵐ⁺¹(r)

Φᵐ(r) = (1/(N−m+1)) · Σᵢ log Cᵢᵐ(r)

Cᵢᵐ(r) = (1/(N−m+1)) · #{ j : max_{k<m} |x_{i+k} − x_{j+k}| ≤ r }
```

Ключевое отличие: `#{ j : ... }` включает `j = i` (совпадение с самим собой),
что даёт систематическое смещение.

## Интерпретация

- **ApEn < 0.5** — регулярная динамика
- **ApEn ≈ 1.5–2.0** — хаос
- **ApEn > 2.0** — белый шум

## Что смотреть в ChaosLab

1. Выберите систему.
2. Нажмите **ApEn** в блоке команд анализа.
3. Результат появится в разделе «СЛОЖНОСТЬ».

## Сравнение с SampEn

Для хаотических систем ApEn и SampEn дают близкие значения
(расхождение 5–15%). Для регулярных систем ApEn может давать ложно
завышенные значения из-за самопарных совпадений.

**Рекомендация:** для новых исследований используйте SampEn.
ApEn оставлен для воспроизведения старых результатов.

## Параметры по умолчанию

- m = 2 (длина паттерна)
- r = 0.2σ (порог как доля стандартного отклонения)

## Применения

- **Медицина** — вариабельность сердечного ритма (HRV)
- **Нейронауки** — анализ ЭЭГ
- **Финансы** — непредсказуемость валютных курсов
- **Геофизика** — анализ сейсмических рядов
