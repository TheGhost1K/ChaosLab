# Резонансный анализ

## Обзор

**Резонансный анализ** проверяет, содержит ли спектр мощности системы
выраженные дискретные пики и связаны ли их частоты рациональными
соотношениями. Это ключевой признак **квазипериодики** — системы на торе.

## Зачем это нужно

Спектр мощности сам по себе показывает наличие пиков, но не говорит,
являются ли они независимыми. Квазипериодическая система с двумя
несоизмеримыми частотами f₁ и f₂ — это **тор**, а не хаос. Если
f₂/f₁ ≈ p/q с малыми p, q, то динамика **резонансная** — устойчивая орбита,
намотанная на тор.

Различение:

| Спектр | f₂/f₁ | Тип |
|--------|-------|-----|
| Один пик | — | Периодика |
| Два пика с иррациональным f₂/f₁ | ≈ 1.618… | Тор (квазипериодика) |
| Два пика с f₂/f₁ = p/q | точно p/q | Резонанс на торе |
| Широкополосный | — | Хаос |

## Алгоритм

1. **FFT** — спектр мощности через `PowerSpectrum.ComputeAsync`.
2. **Поиск локальных максимумов** — топ-N пиков по мощности.
3. **Приближение рациональным**: для каждой пары (f₁, fᵢ) находится
   ближайшее p/q с q ≤ 6 через перебор.
4. **Проверка ошибки**: если |fᵢ/f₁ − p/q| < 0.02 — резонанс найден.

## Что смотреть в ChaosLab

1. Выберите систему с параметрами, дающими квазипериодику — например,
   **Langford** при ν = 0.85, μ = 0.85, γ = 0.5.
2. Нажмите **Resonance** в блоке команд.
3. Результат появится в разделе «РЕЗОНАНСЫ».

Для Лоренца и Rössler (хаос) результат будет: «Резонансы не обнаружены
— широкополосный спектр». Для Langford — до 3–4 соотношений.

## Пример вывода

Для квазипериодической системы:

```text
f₀ = 12 (bin)
Peaks: f1=12, f2=24, f3=36
f2/f1 = 2.003 ≈ 2:1
f3/f1 = 3.001 ≈ 3:1
```

Это чёткий признак 2-тора с резонансом 2:1.

Для хаотической:

```text
f₀ = 8 (bin)
Peaks: f1=8, f2=23, f3=71
Резонансы не обнаружены
(широкополосный спектр — хаос)
```

## Ограничения

- **Оконная функция Ханна** размывает пики на 1–2 бина — точность
  приближения ~1%.
- **Разрешение частот** ограничено длиной ряда: Δf = 1/N.
- **Шум** может создавать «ложные» пики — смотрите на мощность, а не
  только на существование.
- Метод **не отличает** устойчивый предельный цикл от резонанса на
  торе — для этого нужен второй параметр (например, размерность
  аттрактора через D₂).

## Применения

- Астрономия: орбитальные резонансы планет
- Физика плазмы: циклотронные резонансы
- Акустика: обертоны музыкальных инструментов
- Управление хаосом: поиск «окон» периодичности в хаосе
