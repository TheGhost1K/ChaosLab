# Корреляционная размерность D₂

## Что это

**Корреляционная размерность** — мера фрактальной размерности
аттрактора, вычисляемая по статистике парных расстояний между точками
на траектории.

## Формула (Grassberger-Procaccia 1983)

```text
C(r) = 2/(N(N−1)) · #{ (i,j) : |xᵢ − xⱼ| < r }
D₂ = lim_{r→0} d log C(r) / d log r
```

## Как считается в ChaosLab

1. Собираем N = 3000 точек через delay-embedding (Тейкенс).
2. Строим гистограмму попарных расстояний в 64 лог-бинах.
3. Кумулятивная C(r) → линейная регрессия log C vs log r.
4. Наклон = D₂, R² — качество.

## Ожидания

| Система | D₂ |
|---------|-----|
| Lorenz | **2.06** |
| Hénon | **1.26** |
| Rössler | 1.98 |
| Логистика (r=4) | 1.0 |
| Тор | 2.0 |
| Точка | 0.0 |

## Различение структур

- **D₂ = целое** — тор или периодика
- **D₂ нецелое** — фрактал (странный аттрактор)
- **D₂ = 1** — одномерная кривая
- **D₂ = 2** — плоская область
- **D₂ ≈ 1.26 (Hénon)** — между кривой и плоскостью

## Роль embeddingDim и delay

**Delay** — сдвиг между координатами в delay-embedding.
**embeddingDim** — сколько координат берётся.

ChaosLab использует `embeddingDim = Dimension + 1` по умолчанию.
Для корректного выбора — используйте режим **FNN + MI**.

## Проверка корректности

Для D₂ = 2.06 у Лоренца:

- **D₂ < 2.0** — слишком маленькое embeddingDim
- **D₂ > 2.2** — слишком большое r (нелинейная область)
- **R² < 0.99** — плохое качество аппроксимации
