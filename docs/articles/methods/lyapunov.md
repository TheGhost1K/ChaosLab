# Показатели Ляпунова

## Что это

**Показатели Ляпунова** λ₁ ≥ λ₂ ≥ ... ≥ λₙ — фундаментальная характеристика
динамической системы, измеряющая скорость экспоненциального расхождения
близких траекторий.

Математически: если рассмотреть две траектории с начальным расхождением
δx₀, то через время t:

```text
|δx(t)| ≈ |δx(0)| · e^(λ₁·t)
```

## Классификация динамики

| Спектр λ | Тип динамики |
|----------|--------------|
| λ₁ < 0 (все) | Устойчивое равновесие |
| λ₁ = 0, λ₂ < 0 | Периодическая орбита |
| λ₁ = λ₂ = 0 | Квазипериодика (тор) |
| λ₁ > 0 | **Хаос** |
| λ₁ > 0, λ₂ > 0 | Гиперхаос |

## Как ChaosLab считает спектр

Используется **QR-метод Бенеттина** (1980):

### Идея

Мы хотим отслеживать, как деформируется n-мерный «элемент объёма»
вдоль траектории. Матрица Якоби J(x) описывает мгновенную деформацию.

### Алгоритм

1. Заводим матрицу Q = I (n столбцов — ортонормированный базис).
2. На каждом шаге:
   ```
   W ← J(x)·Q
   Q·R ← QR(W)         (разложение)
   λᵢ += log|Rᵢᵢ|
   ```
3. Продвигаем траекторию: `x ← f(x)`.

4. По окончании: `λᵢ = λᵢ_накопленное / T`.

### Почему QR

Если этого не делать, все столбцы Q быстро «схлопнутся» на направление
максимального роста (старший показатель). QR заставляет их оставаться
ортогональными, позволяя отследить **все** показатели.

## Численные детали

### Разложение QR

ChaosLab использует **метод Хаусхолдера** вместо Gram-Schmidt. Причина:
Gram-Schmidt теряет ортогональность на ~10⁶ шагах, Householder остаётся
точным до 10¹².

### Вариационный vs двухтраекторный

**Классический двухтраекторный** метод:
- Держит 2 полные траектории
- На каждом шаге считает расстояние между ними
- Медленно, но просто

**Вариационный** метод (в ChaosLab):
- Держит 1 траекторию + вектор отклонения w
- `ẇ = J(x)·w` — одна JVP на шаг RK4
- **В 2 раза быстрее**, точнее

Для этого в каждой системе переопределён `JacobianVectorProduct`.

## Проверка

Для системы Лоренца (σ=10, ρ=28, β=8/3):

```text
λ₁ ≈ +0.906
λ₂ ≈ 0
λ₃ ≈ −14.572
Σλᵢ = −(σ+1+β) = −13.666
```

Последнее равенство — **теорема о дивергенции**: сумма показателей
равна среднему по времени от следа якобиана.

Для Hénon (a=1.4, b=0.3):

```text
λ₁ + λ₂ = log|b| = −1.204
```

Это **инвариант**, не зависящий от метода расчёта.

## Как использовать в ChaosLab

1. Выберите систему.
2. Нажмите **λ Спектр** в правой панели.
3. Дождитесь результата (обычно 1–5 сек).

Результат:

```text
λ[0] = +0.9062
λ[1] = +0.0001
λ[2] = -14.5718

✓ Хаос: 1 λ > 0 из 3
D_KY = 2.06
```

## Карта Ляпунова

Более информативный вариант — **карта λ₁(p₁, p₂)**, где цвет кодирует
старший показатель в плоскости двух параметров. Позволяет найти границу
хаоса и «острова» периодичности.

## Применения

- **Прогноз погоды** — предел предсказуемости ≈ 1/λ₁
- **Управление хаосом** — стабилизация неустойчивых орбит
- **Криптография** — оценка «качества» хаотических генераторов
- **Физиология** — анализ ЭЭГ/ЭКГ
