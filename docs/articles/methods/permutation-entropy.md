# Permutation Entropy

## Обзор

**Permutation Entropy (PermEn)** — мера **сложности** временного ряда,
основанная на **порядке** элементов, а не на их значениях. Предложена
Bandt и Pompe в 2002 году.

Идея: возьмём окно длиной m, отсортируем элементы по возрастанию,
запишем порядок индексов (паттерн). PermEn — энтропия распределения
таких паттернов.

## Формула

Для каждого окна x[i], x[i+τ], ..., x[i+(m−1)τ] находим permutation π —
перестановку индексов, упорядочивающую элементы. Всего **m!** возможных
паттернов. Тогда:

```text
H = −Σπ p(π) · log p(π)
PermEn = H / log(m!)
```

Результат нормализован в **[0, 1]**.

## Интерпретация

- **PermEn = 0** — монотонный ряд (только один паттерн)
- **PermEn ≈ 0.5–0.7** — умеренная сложность
- **PermEn ≈ 0.9–1.0** — почти случайный
- **PermEn = 1** — все паттерны равновероятны

**Отличие от SampEn:** PermEn не зависит от распределения значений,
устойчива к монотонным преобразованиям.

## Параметры по умолчанию

- **m = 3** — длина паттерна (обычно 3–7)
- **τ = 1** — задержка

## Ожидаемые значения

| Система | PermEn |
|---|---|
| Монотонный ряд | 0.0 |
| Периодика (синус) | ≈ 0.5 |
| Логистика (r = 4) | ≈ 0.98 |
| Lorenz | ≈ 0.9 |
| Hénon | ≈ 0.85 |
| Белый шум | ≈ 1.0 |

## Преимущества

- **Устойчива к шуму:** малые возмущения не меняют порядок
- **Быстрая:** O(N·m·log m) вместо O(N²) у SampEn
- **Не требует нормировки:** r не нужно
- **Инвариантна** к монотонным преобразованиям

## Ограничения

- **Малые m** дают грубую оценку. **Большие m** — плохо для коротких рядов
  (нужно N ≫ m!).
- **Игнорирует амплитуду:** резкий скачок и мягкое изменение могут дать
  один и тот же паттерн.

## Применения

- **ЭЭГ/ЭКГ** — глубина анестезии, эпилепсия
- **Криптография** — качество генераторов
- **Финансы** — турбулентность рынков
- **Климат** — предсказуемость температурных рядов
