# Адаптивные интеграторы

## Обзор

**Adaptive Runge–Kutta 45** (Dormand–Prince) — интегратор 5-го порядка
с **встроенной оценкой локальной ошибки**. В отличие от классического RK4,
шаг автоматически подстраивается под динамику системы.

## Как работает

На каждом шаге вычисляются два решения:
- **5-го порядка** — принимаемое
- **4-го порядка** — вспомогательное

Разность между ними даёт оценку ошибки ε. Если ε > tol, шаг отклоняется
и уменьшается. Если ε << tol, шаг увеличивается.

## Преимущества

| Свойство | RK4 (fixed dt) | RK45 (adaptive) |
|---|---|---|
| Порядок точности | 4 | 5 |
| Управление ошибкой | Нет | Да |
| Быстрые системы | Замедляется | Работает быстро |
| Медленные системы | Разрушается | Увеличивает dt |
| Stiff системы | Не работает | Справляется |

## Когда использовать

- **Langford, Nose-Hoover** — системы с широким спектром масштабов
- **Hénon-Heiles при E близко к 1/6** — траектория уходит на ∞
- **Проверка точности** — сравнение с RK4 при малых tol

## В ChaosLab

Включите чекбокс **Use Adaptive RK45** в блоке РЕНДЕР. Слайдер
**Tolerance** управляет точностью:

- `1e-6` — высокая точность (медленно)
- `1e-4` — баланс (по умолчанию)
- `1e-3` — быстрая визуализация
