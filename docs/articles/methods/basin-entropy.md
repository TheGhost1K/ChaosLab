# Basin Entropy

## Обзор

**Basin entropy** — Shannon-энтропия распределения меток в карте бассейнов
притяжения. Показывает, насколько **«демократично»** фазовое пространство
распределено между аттракторами.

## Формула

Для карты бассейнов с N точками и K аттракторами:

```text
H = −Σₖ pₖ · log₂ pₖ
```

где `pₖ` — доля точек, притягиваемых k-м аттрактором.

Нормализованная версия:

```text
H_norm = H / log₂(K) ∈ [0, 1]
```

## Интерпретация

- **H = 0** — все точки притягиваются одним аттрактором (нет мультистабильности)
- **H = log₂ K** — аттракторы равноправны (сложная фрактальная граница)
- **0 < H < log₂ K** — промежуточный случай

`H_norm`:
- **H_norm = 0** — один доминирующий аттрактор
- **H_norm = 1** — равные бассейны

## Что смотреть в ChaosLab

## Ожидаемые значения

| Система | K | H | H_norm |
|---|---|---|---|
| Lorenz (2 точки равновесия) | 2 | ≈ 1.0 | ≈ 1.0 |
| Newton-Leipnik | 2 | ≈ 0.8–1.0 | 0.8–1.0 |
| Hénon | 1 | 0 | 0 |
| Устойчивый фокус | 1 | 0 | 0 |

## Фрактальная структура границ

Главный интерес basin entropy — **связь с фрактальной структурой**
границы между бассейнами. Если границы фрактальны, энтропия оказывается
близкой к максимуму.

Метрика **uncertainty exponent α** (Grebogi et al. 1983):

```text
f(ε) = fraction of ε-boxes containing more than one attractor
f(ε) ~ ε^α
```

- **α = d − 1** — гладкая граница
- **α < d − 1** — фрактальная граница

Это более точная мера, чем basin entropy, но требует многократного
построения карт на разных масштабах.

## Применения

- **Динамика** — количественная оценка мультистабильности
- **Экология** — распределение между устойчивыми состояниями экосистемы
- **Климат** — границы бассейнов ледниковых/межледниковых периодов
- **Электроника** — конкуренция между режимами автогенераторов

## Ограничения

- **Зависит от окна начальных условий** — если окно выбрано неудачно,
  энтропия может быть недооценена.
- **Требует ≥ 2 аттракторов** — для моностабильных систем бессмысленна.
- **Чувствительна к разрешению карты** — при слишком грубом разрешении
  энтропия завышается.
