# Return Map

## Обзор

**Return map** (отображение возврата, first-return map) — способ свести
**поток** к **1D-отображению**. Идея: взять локальные максимумы одной
из координат и построить зависимость xₙ → xₙ₊₁.

Это **то же самое**, что сечение Пуанкаре через специально выбранную
плоскость — но метод автоматически находит плоскость.

## Как работает в ChaosLab

**Для потоков:**

1. Интегрируется траектория.
2. Детектируются локальные максимумы координаты x(t)
   (трёхточечный детектор: `x[i−1] > x[i−2] && x[i−1] ≥ x[i]`).
3. Пары последовательных максимумов (xₙ, xₙ₊₁) наносятся точками.

**Для дискретных отображений:**

Просто наносятся точки (xₙ, xₙ₊₁) вдоль траектории.

## Классический пример — Lorenz

Для Lorenz return map даёт **тентоподобную кривую**, похожую на
логистическую параболу. Это **эмпирическое открытие Лоренца**: хаос
в 3D можно свести к одномерному отображению.

Именно этот график вдохновил Отто Рёсслера и других исследователей
на поиск универсальности в хаосе.

## Что смотреть в ChaosLab

Режим **Return Map** в комбобоксе РЕЖИМ.

**Попробуйте на:**

- **Lorenz** → тентоподобная кривая
- **Rössler** → плоская кривая (return map вырожден)
- **Logistic** → парабола (xₙ против xₙ₊₁)
- **Hénon** → фрактальная кривая

## Ожидаемые результаты

| Система | Форма return map |
|---|---|
| Logistic | Парабола y = r·x(1−x) |
| Lorenz | Тентоподобная кривая |
| Hénon | Двузначная кривая |
| Ikeda | Сложная многослойная |
| Периодика | Дискретные точки |

## Что это даёт

- **Понимание топологии аттрактора.** Return map часто имеет
  простую форму даже для сложного потока.
- **Сведение размерности.** 3D-хаос → 1D-отображение → можно
  применить всю теорию одномерных отображений.
- **Связь между системами.** Если два потока дают похожие return maps —
  они, вероятно, топологически эквивалентны.

## Ограничения

- **Работает только для 1D-проекций.** Если максимумы x(t) не отражают
  всю динамику — картина искажена.
- **Требует гладкости.** Для систем с шумом или ударами — неприменим.

## Применения

- **Теория хаоса** — универсальность отображений
- **Физика лазеров** — динамика интенсивности
- **Биология** — return map для нейронных спайков
- **Астрофизика** — орбитальная динамика
