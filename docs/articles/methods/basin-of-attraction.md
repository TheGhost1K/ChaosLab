# Бассейны притяжения

## Обзор

**Бассейн притяжения аттрактора** — множество начальных условий,
из которых траектория сходится к этому аттрактору.

В системе с **несколькими** аттракторами (мультистабильной) важно
знать, где границы бассейнов. Для хаотических систем эти границы
**фрактальны**.

## Что показывает карта бассейнов

Каждая точка начальных условий окрашивается по номеру аттрактора,
к которому она притягивается. Получается **карта** с разноцветными
областями.

Для гладких систем границы бассейнов — гладкие кривые.
Для хаотических — **фракталы**: границы бесконечно изрезаны, и
сколь угодно малое изменение начальных условий может привести
к другому аттрактору.

## Как считается в ChaosLab

1. Задаётся окно начальных условий (x₀, y₀).
2. Для каждой точки окна:
   - Прогрев на transient шагов
   - Усреднение за minSamples шагов → «центр» аттрактора
3. Кластеризация центров по порогу → метка аттрактора.
4. Рендер карты через палитру.

## Что смотреть в ChaosLab

Раздел **ГЕОМЕТРИЯ** → кнопка **Бассейны**.

**Попробуйте на:**

- **Newton-Leipnik** — два аттрактора, тонкая граница
- **Lorenz** — два «фокуса» C+ и C−
- **Hénon** — в некоторых режимах есть несколько циклов

## Ожидаемый вид

Для Newton-Leipnik с двумя аттракторами:

- Левая половина окна → аттрактор A (красный)
- Правая → аттрактор B (синий)
- Граница между ними — **фрактальная**

## Basin Entropy

Связанная метрика — **Basin entropy**. Это Shannon-энтропия
распределения меток:

```text
H = −Σₖ pₖ · log₂ pₖ
```

- **H = 0** — один аттрактор доминирует
- **H = log₂ K** — все аттракторы равноправны

ChaosLab считает **Basin entropy** автоматически при построении бассейнов
(раздел ПРЕДСКАЗУЕМОСТЬ).

## Ограничения

- **Медленно.** Карта 200×200 требует 200×200×(transient + minSamples)
  шагов. Для потока с dt = 0.01 это минуты.
- **Зависит от окна.** Если окно выбрано неудачно — увидите только один
  бассейн.
- **Разрешение ограничено.** При грубом разрешении фрактальная структура
  границы теряется.

## Применения

- **Лазеры** — конкуренция мод
- **Климат** — ледниковые/межледниковые состояния
- **Экология** — альтернативные устойчивые состояния экосистемы
- **Электроника** — бистабильные мультивибраторы
