# Box-counting dimension

## Обзор

**Box-counting dimension** — простейший способ оценить фрактальную
размерность множества. Работает напрямую по изображению аттрактора.

## Алгоритм

1. Разбить изображение на сетку из квадратов размера ε.
2. Посчитать число **непустых** квадратов N(ε).
3. Повторить для ε = 1, 2, 4, 8, ..., 128.
4. Наклон log N(ε) vs log(1/ε) = **D_box**.

## Формула

```text
D_box = lim_{ε→0} log N(ε) / log(1/ε)
```

## Интерпретация

- **D = 1** — кривая (прямая, окружность)
- **D = 2** — плоская область
- **D = 1.26** — Hénon (фрактальная кривая)
- **D ≈ 2.06** — Lorenz (слегка «толще» плоскости)

Для **простых** множеств D_box — целое. Для **фракталов** — дробное.

## Что смотреть в ChaosLab

Раздел **РАЗМЕРНОСТИ** в правой панели. Результат появляется автоматически
после каждого рендера.

**Обратите внимание:** D_box пересчитывается при каждом рендере, потому
что зависит от буфера плотности.

## Ожидаемые значения

| Система | D_box | D₂ |
|---|---|---|
| Lorenz | ≈ 2.06 | 2.06 |
| Hénon | ≈ 1.26 | 1.26 |
| Rössler | ≈ 2.0 | 1.98 |
| Logistic (r = 4) | ≈ 1.0 | 1.0 |

Для большинства аттракторов **D_box ≈ D₂**, но D_box менее точен —
ошибка до ±0.1 из-за дискретизации.

## Отличие от D₂

| Свойство | D_box | D₂ |
|---|---|---|
| Вход | Пиксели | Точки траектории |
| Сложность | O(N) | O(N²) |
| Точность | Грубая | Высокая |
| Устойчивость | Зависит от разрешения | R² показывает качество |

## Ограничения

- **Требует заполненного аттрактора.** Если рендер построил только часть —
  размерность будет занижена.
- **Разрешение ограничено.** При 1024×1024 минимальный ε = 1, максимальный
  = 128. Этого достаточно для большинства систем.
- **Для 1D отображений бесполезна** — проекция вырождена.

## Применения

- **География** — размерность береговой линии
- **Биология** — размерность нейронных сетей
- **Материаловедение** — пористая структура
- **Динамика** — быстрая оценка фрактальности
