# Lempel–Ziv Complexity

## Обзор

**Lempel–Ziv complexity** (LZ76) — мера **алгоритмической сложности**
временного ряда. Показывает, сколько «новых» подслов нужно, чтобы
закодировать последовательность.

Идея восходит к теории Колмогорова: сложность объекта — это длина самой
короткой программы, которая его порождает. LZ76 — практическая реализация
для конечных последовательностей.

## Формула

Для бинаризованного ряда длины n:

```text
c(n) = C(n) · log₂(n) / n
```

где `C(n)` — число уникальных подслов, найденных алгоритмом LZ76.
Результат нормирован в [0, 1].

## Интерпретация

- **c ≈ 0.2–0.3** — регулярная динамика (периодика, точки)
- **c ≈ 0.5–0.7** — хаос
- **c ≈ 1.0** — белый шум (максимальная алгоритмическая сложность)

**Важно:** хаос **сложнее** периодики, но **проще** шума. Это одна из
причин, по которой хаос называют «структурированной сложностью» —
между порядком и беспорядком.

## Бинаризация

ChaosLab использует **порог по медиане**:

```text
sᵢ = 1, если xᵢ ≥ median(x)
sᵢ = 0, иначе
```

Это устойчиво к нестационарности и не требует знания распределения ряда.

## Что смотреть в ChaosLab

1. Выберите систему.
2. Нажмите **LZ** в блоке команд.
3. Результат — в разделе «СЛОЖНОСТЬ».

## Ожидаемые значения

| Система | c(n) |
|---|---|
| Точка | 0.1–0.2 |
| Логистика (r = 3.5, 4-цикл) | 0.3–0.4 |
| Логистика (r = 4) | 0.7–0.8 |
| Лоренц | 0.75–0.85 |
| Белый шум | 0.9–1.0 |

## Сравнение с энтропиями

- **SampEn/ApEn** — вероятностная мера (сколько «неожиданности» в среднем)
- **LZ** — комбинаторная мера (сколько различных подслов нужно закодировать)
- **PermEn** — порядковая мера (какие ординальные паттерны бывают)

Все три меры независимы и дают разную информацию.

## Применения

- **Нейронауки** — анализ ЭЭГ под наркозом (LZ падает)
- **Медицина** — обнаружение эпилепсии
- **Криптография** — оценка качества генераторов
- **ДНК-анализ** — сложность генома

## Ограничения

- **Чувствительна к длине ряда** — при N < 500 статистика плохая.
- **Требует стационарности** — при трендах искажается.
- **Результат зависит от порога бинаризации** — мы используем медиану
  как компромисс.
