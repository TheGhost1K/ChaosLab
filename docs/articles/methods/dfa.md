# Detrended Fluctuation Analysis (DFA)

## Обзор

**DFA** — устойчивый к нестационарности аналог экспоненты Хёрста.
Предложен Peng et al. в 1994 году для анализа физиологических сигналов.

Идея: вместо R/S использовать **средний квадрат отклонения от локального
тренда**. Это убирает влияние медленных трендов.

## Алгоритм

1. Проинтегрировать ряд: `y(k) = Σ (x_i − ⟨x⟩)`.
2. Разбить на блоки длиной n.
3. В каждом блоке — линейная регрессия (тренд).
4. F(n) = RMS отклонений от локального тренда.
5. Наклон log F(n) vs log n = **α**.

## Интерпретация

| α | Тип ряда |
|---|---|
| α ≈ 0.5 | Белый шум |
| α ≈ 0.75 | 1/f^(1/2) |
| α ≈ 1.0 | 1/f (розовый шум) |
| α ≈ 1.5 | Броуновское движение |
| α > 1.0 | Персистентность |
| α < 0.5 | Антиперсистентность |

## Что смотреть в ChaosLab

Раздел **СТАТИСТИКА**. Нажмите **DFA**.

## Ожидаемые значения

| Система | α_DFA |
|---|---|
| Белый шум | ≈ 0.5 |
| Lorenz | ≈ 1.2–1.4 |
| Rössler | ≈ 1.4 |
| Броуновское движение | ≈ 1.5 |

Для хаотических систем α_DFA > 1 — сильная персистентность.

## Отличие от Hurst

| Свойство | Hurst (R/S) | DFA |
|---|---|---|
| Убирает тренд | Нет | **Да** |
| Устойчивость к нестационарности | Низкая | **Высокая** |
| Применимость | Стационарные ряды | Любые |
| Смысл H vs α | Один и тот же для стационарных | |

**Правило:** если Hurst и DFA дают схожие значения — ряд стационарен,
оба метода валидны. Если Hurst сильно меньше DFA — ряд нестационарен,
Hurst недооценивает.

## Применения

- **Кардиология** — HRV, детекция аритмий
- **Нейронауки** — анализ ЭЭГ
- **Метеорология** — долгосрочные корреляции температуры
- **Геномика** — корреляции в ДНК

## Литература
