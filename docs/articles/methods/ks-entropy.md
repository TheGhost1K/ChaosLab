# Энтропия Колмогорова–Синая

## Обзор

**Колмогоров–Синая энтропия (h_KS)** — фундаментальная характеристика
динамической системы. По теореме Песина (1977):

```text
h_KS = Σᵢ max(λᵢ, 0)
```

то есть **сумма положительных показателей Ляпунова**.

## Физический смысл

h_KS — **скорость производства информации** системой. Единицы: наты
на единицу времени.

- **h_KS = 0** — система детерминирована, информация не создаётся
- **h_KS > 0** — хаос, каждую секунду система «придумывает» h_KS натов
  новой информации

## Отличие от λ₁

λ₁ говорит о скорости расхождения **ближайших** траекторий.
h_KS учитывает **все** неустойчивые направления.

| Система | λ₁ | h_KS |
|---|---|---|
| Лоренц | 0.906 | **0.906** |
| Chen | 2.03 | **2.03** |
| Лоренц-96 (N=8, F=8) | 1.50 | **~2.8** (5 положительных λ) |
| Гиперхаос | +0.5 | **>1.0** |

Для систем с **одним** положительным показателем (обычный хаос) h_KS = λ₁.
Для гиперхаоса h_KS > λ₁ — это признак **более сильного** хаоса.

## Гиперхаос

Если у системы **больше одного** положительного λ, её называют
**гиперхаотической**. Примеры:

- **Lorenz-96** при N ≥ 8, F ≥ 8 — типичный гиперхаос
- **Rössler hyperchaos** (4D расширение) — λ₁, λ₂ > 0
- **Chua's circuit** с дополнительной индуктивностью — 4D гиперхаос

Гиперхаос важен в **криптографии** — генераторы на его основе устойчивее
к атакам.

## Что смотреть в ChaosLab

1. Выберите систему.
2. Нажмите **h_KS**.
3. Результат — в разделе «ЭНТРОПИЯ KS».

Отобразится:
- Само значение h_KS
- Число положительных λ
- Метка «⚠ Гиперхаос» или «✓ Хаос»

## Как использовать

- **Для систем с одним положительным λ** — h_KS совпадает с λ₁, отдельной
  информации не даёт.
- **Для Lorenz-96** — h_KS показывает **общее** количество хаоса,
  включая все неустойчивые направления.
- **Для сравнения систем** — h_KS удобнее λ₁, потому что не зависит
  от того, «случайно» ли λ₂ близко к нулю.

## Применения

- **Прогноз погоды** — предел предсказуемости 1/h_KS
- **Криптография** — оценка качества хаотических генераторов
- **Data assimilation** — сколько информации нужно передать для
  восстановления состояния
