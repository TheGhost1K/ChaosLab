# Сечения Пуанкаре

## Обзор

**Сечение Пуанкаре** — мощный метод визуализации динамики **потоков**.
Вместо того чтобы рисовать всю траекторию в 3D, мы фиксируем плоскость
и отмечаем **точки её пересечения** траекторией.

Это **редукция размерности**: непрерывный поток превращается в дискретное
отображение на плоскости.

## Как работает в ChaosLab

1. Выбирается плоскость `z = z₀`.
2. Интегрируется траектория.
3. Когда траектория пересекает плоскость в направлении sign,
   добавляется точка в **сечение**.
4. Между соседними шагами — линейная интерполяция точки пересечения.

## Что это даёт

**Периодический поток** → конечное число точек (одна на период).

**Квазипериодический поток (тор)** → замкнутая кривая (заполняется
медленно).

**Хаотический поток** → фрактальное множество точек
(«странный аттрактор» в срезе).

## Что смотреть в ChaosLab

Раздел **ГЕОМЕТРИЯ** → кнопка **Пуанкаре**.

Для **Lorenz** при z₀ = 27 в сечении получится знаменитая
**тентоподобная кривая** — одномерное отображение, порождённое
трёхмерным потоком.

## Классический пример — Lorenz

Сечение Лоренца при z = 27, sign = +1 даёт **фрактальное множество**,
похожее на логистическую параболу. Именно оно вдохновило Лоренца
на идею, что хаос в 3D можно свести к 1D-отображению.

## Ожидаемые результаты

| Система | Сечение |
|---|---|
| Lorenz | Тентоподобная кривая |
| Rössler | Кольцо точек |
| Chua | Два независимых кластера |
| Thomas | Несколько полос |
| Периодический цикл | 1 точка |

## Ограничения

- **Только для потоков (Flow).** Дискретные отображения уже «сечены» —
  они сами по себе задают последовательность.
- **Требует разумного z₀.** Если плоскость далеко от аттрактора,
  точек будет мало.
- **Требует долгого времени наблюдения.** Хаотическое сечение заполняется
  медленно.

## Применения

- **Астрофизика** — динамика Солнечной системы
- **Химия** — колебательные реакции
- **Биология** — модели нейронов
- **Механика** — системы с ударами
