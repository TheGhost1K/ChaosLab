# Мультифрактальный анализ

## Что это

**Мультифрактал** — множество, у которого разные части имеют разные
фрактальные размерности. Для аттракторов это означает, что локальная
размерность меняется от точки к точке.

## Обобщённые корреляционные суммы

```text
C_q(r) = [1/(N−1) · Σ pᵢ^(q−1)]^(1/(q−1))
```

где pᵢ — вероятность попасть в i-й шар радиуса r.

## Обобщённые размерности

```text
D_q = lim_{r→0} log C_q(r) / log r
```

- **D₀** — box-counting
- **D₁** — информационная
- **D₂** — корреляционная
- **D₋∞ … D₊∞** — полный спектр

## Спектр сингулярностей f(α)

Через преобразование Лежандра:

```text
τ(q) = (q−1)·D_q
α = dτ/dq
f(α) = q·α − τ(q)
```

**Ширина f(α)** — мера мультифрактальности:

- **Одна точка** — монофрактал
- **Широкий спектр** — мультифрактал

## Что смотреть в ChaosLab

1. Выберите систему.
2. Режим → **Multifractal**.
3. Увидите график D_q от q.

Типичная картина для хаоса: D_q монотонно убывает.

## Ожидания

- **Лоренц:** D₂ ≈ 2.06, D₀ ≈ 2.1, D₁ ≈ 2.07
- **Логистика (r=4):** D_q ≈ 1 для всех q (монофрактал)
- **Случайный шум:** D_q = d (dimension) для всех q

## Применения

- Анализ турбулентности
- Мультифрактальные финансы (Mandelbrot)
- Физиология (вариабельность сердечного ритма)
- Геофизика (распределение землетрясений)
