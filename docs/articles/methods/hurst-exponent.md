# Экспонента Хёрста

## Обзор

**Экспонента Хёрста (H)** — мера **персистентности** временного ряда.
Показывает, есть ли «память»: склонны ли большие значения следовать
за большими, а малые за малыми.

Введена Гарольдом Хёрстом в 1951 году при изучении разливов Нила.

## Формула (R/S-анализ)

Для блока длиной n вычисляется:

```text
R(n) / S(n) ~ n^H
```

где R — размах кумулятивных отклонений, S — стандартное отклонение.
H находится как наклон log(R/S) vs log(n).

## Интерпретация

| H | Тип ряда |
|---|---|
| H = 0.5 | Белый шум (нет памяти) |
| H > 0.5 | Персистентность (тренд) |
| H < 0.5 | Антиперсистентность (возврат к среднему) |
| H ≈ 1.0 | Сильный тренд |

## Ожидаемые значения

| Система | H |
|---|---|
| Белый шум | ≈ 0.5 |
| Логистика (r = 4) | ≈ 0.5–0.6 |
| Lorenz | ≈ 0.85–0.95 |
| Rössler | ≈ 0.85 |
| Броуновское движение | ≈ 1.0 |

**Обратите внимание:** хаотические аттракторы обычно дают **H ≈ 0.85–0.95** —
очень высокая персистентность. Это следствие гладкости траектории:
ряд x(t) медленно меняется.

## Отличие от DFA

Стандартный R/S-анализ **чувствителен к нестационарности**. Если ряд
имеет тренд или сезонность — H будет завышена.

**DFA (Detrended Fluctuation Analysis)** — устойчивый аналог, который
сначала убирает тренд в каждом блоке. Для стационарных рядов H и α_DFA
совпадают.

**Совет:** если Hurst и DFA дают разные значения — ряд нестационарен,
и DFA надёжнее.

## Применения

- **Гидрология** — уровни рек (сама Хёрст изучала разливы Нила)
- **Финансы** — персистентность волатильности
- **Климат** — долговременная память температур
- **Физиология** — вариабельность сердечного ритма
