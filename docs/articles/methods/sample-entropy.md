# Sample Entropy

## Обзор

**Sample Entropy (SampEn)** — мера **непредсказуемости** временного
ряда. Предложена Richman и Moorman в 2000 году как устойчивая
альтернатива Approximate Entropy.

Идея: если два паттерна длиной m совпадают, SampEn измеряет вероятность,
что они совпадут и на длине m+1. Чем ниже вероятность, тем менее
предсказуема система.

## Формула

```text
SampEn(m, r) = −log(A / B)
```

где:

- **B** — число пар длины **m** с расстоянием < r
- **A** — число тех же пар, где и (m+1)-й элемент ближе r
- **r** — обычно 0.2·σ (20% от стандартного отклонения)

**Важно:** пары (i, i) **исключены**. Это главное отличие от ApEn.

## Интерпретация

| SampEn | Тип сигнала |
|---|---|
| < 0.5 | Регулярный (периодика, точка) |
| 0.5–1.5 | Умеренная сложность |
| 1.5–2.5 | Хаос |
| > 2.5 | Белый шум |

## Что смотреть в ChaosLab

Раздел **ЭНТРОПИИ** в правой панели. Нажмите **Entropy** для запуска.

Результат:

```text
SampEn(2, 0.2σ) = 0.0783
PermEn(m=3)     = 0.4040
```

## Параметры по умолчанию

- **m = 2** — длина паттерна
- **r = 0.2σ** — порог близости

Оба значения — стандарт из оригинальной статьи Richman & Moorman.

## Ожидаемые значения

| Система | SampEn |
|---|---|
| Устойчивая точка | ≈ 0 |
| Логистика (r = 3.5, 4-цикл) | < 0.1 |
| Логистика (r = 4) | ≈ 0.7 |
| Lorenz | ≈ 0.07–0.15 |
| Rössler | ≈ 0.1–0.3 |
| Белый шум | ≈ 2.2 |

**Парадокс:** SampEn для хаоса **ниже**, чем для белого шума.
Это правильно — хаос детерминирован, соседние точки «склеены»,
SampEn это видит.

## Отличие от ApEn

| Свойство | SampEn | ApEn |
|---|---|---|
| Самопарные совпадения | Исключены | Включены |
| Смещение при малых N | Малое | Большое |
| Дисперсия | Низкая | Высокая |
| Согласованность | Высокая | Средняя |

**Вывод:** SampEn устойчивее, поэтому используется в современной
литературе как стандарт.

## Применения

- **Кардиология** — вариабельность сердечного ритма (HRV)
- **Нейронауки** — глубина анестезии по ЭЭГ
- **Финансы** — предсказуемость валют
- **Метеорология** — устойчивость климатических рядов
