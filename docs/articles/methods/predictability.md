# Горизонт предсказуемости

## Обзор

**Predictability horizon** — практическая метрика, показывающая,
**через какое время** предсказание станет бесполезным.

В отличие от λ₁ (абстрактная скорость расхождения), горизонт предсказуемости
даёт **число в единицах времени** — его можно интерпретировать физически.

## Формула

Ошибка растёт экспоненциально:

```text
δ(t) = ε₀ · e^(λ₁·t)
```

Предсказание «испортится», когда δ(t) станет сравнимо с размером
аттрактора Δ:

```text
t_h = (1/λ₁) · log(Δ / ε₀)
```

где:
- **ε₀** — начальная точность измерения (обычно 10⁻³)
- **Δ** — характерный размер аттрактора

## Что смотреть в ChaosLab

1. Выберите систему.
2. Нажмите **Predictability**.
3. Результат — в разделе «ПРЕДСКАЗУЕМОСТЬ».

Отобразится:
- λ₁
- Оценка размера аттрактора Δ
- **Горизонт предсказуемости t_h** в единицах времени системы

## Ожидаемые значения

### Лоренц (σ = 10, ρ = 28, β = 8/3)

```text
λ₁ = 0.906
Δ  = 40
ε₀ = 10⁻³
t_h = 11.7 t.e.
```

Это **исторически важное значение**: сам Лоренц отмечал, что предсказания
его модели «работают» около 10 единиц времени, после чего погрешность
становится настолько большой, что прогноз теряет смысл.

### Другие системы

| Система | t_h (при ε₀ = 10⁻³) |
|---|---|
| Lorenz | ~12 |
| Rössler | ~100 (λ₁ мал) |
| Chua | ~40 |
| Logistic (r = 4) | ~10 (в единицах итераций) |
| Hénon | ~20 |
| Lorenz-96 (F = 8) | ~8 |

## Интерпретация

- **t_h > 100** — «предсказуемая» система (для практических целей)
- **10 < t_h < 100** — умеренная предсказуемость
- **t_h < 10** — быстро теряет предсказуемость, нужны частые измерения
- **t_h = ∞** — λ₁ ≤ 0, устойчивая система

## Практическое применение

Метрика позволяет ответить на вопрос: **как часто нужно измерять
состояние системы**, чтобы удерживать погрешность ниже порога?

Если t_h = 12 t.e., а измерительные приборы имеют ε₀ = 10⁻³,
нужно обновлять данные не реже, чем раз в 12 единиц времени.

Именно поэтому:
- **Прогноз погоды** работает на 5–10 дней — это соответствует t_h
  атмосферы ≈ 10 дней при λ₁ ≈ 0.3 / день
- **Прогноз климата** возможен на десятилетия вперёд, потому что
  усреднённые величины подчиняются другим законам (не хаотическим)

## Ограничения

- **Односторонняя оценка** — реальная ошибка может расти быстрее
  из-за нелинейных эффектов.
- **Не учитывает шум** — модель предполагает чисто детерминированную
  динамику.
- **Δ зависит от выбора координаты** — ChaosLab использует максимальный
  диапазон по всем координатам.

## Применения

- **Метеорология** — пределы численного прогноза погоды
- **Data assimilation** — планирование частоты измерений
- **Управление хаосом** — оценка требуемой скорости обратной связи
- **Криптография** — оценка времени «взлома» хаотического шифра
