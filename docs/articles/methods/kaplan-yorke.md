# Kaplan-Yorke dimension

## Обзор

**D_KY** — оценка фрактальной размерности аттрактора **по спектру
Ляпунова**. Не требует ни пикселей, ни попарных расстояний — использует
только λ₁, λ₂, …, λₙ.

Формула предложена Капланом и Йорке в 1979 году как теоретическая
верхняя граница для информационной размерности D₁.

## Формула

Пусть λ₁ ≥ λ₂ ≥ ... ≥ λₙ — спектр Ляпунова. Пусть **j** — наибольший
индекс, при котором сумма λ₁ + ... + λⱼ ≥ 0. Тогда:

```text
D_KY = j + (λ₁ + ... + λⱼ) / |λ_{j+1}|
```

## Физический смысл

Показатели Ляпунова говорят: сколько направлений «растягивается»
(λ > 0) и сколько «сжимается» (λ < 0). D_KY «считает»: сколько целых
растягивающихся направлений плюс какую часть следующего — и получает
**эффективную размерность** аттрактора.

## Ожидаемые значения

| Система | Спектр λ | D_KY |
|---|---|---|
| Lorenz | [0.906, 0, −14.57] | **2.06** |
| Hénon | [0.419, −1.623] | **1.26** |
| Rössler | [0.071, 0, −5.39] | **2.01** |
| Logistic (r = 4) | [0.693] | **1.00** |
| Устойчивая точка | [−0.5, −1, −2] | **0.00** |

## Как считается в ChaosLab

D_KY вычисляется **автоматически** после спектра Ляпунова. Значение
показывается в разделе **СПЕКТР ЛЯПУНОВА** под основным спектром:

```text
λ[0] = +0.9062
λ[1] = +0.0001
λ[2] = −14.5718

✓ Хаос: 1 λ > 0 из 3
D_KY = 2.06
```

## Сравнение с D₂

**Идея:** D_KY — это **верхняя граница** для D₂. Если ваши значения
сильно расходятся (например, D₂ = 1.5, D_KY = 2.5) — это может означать:

- Слишком мало точек для D₂ (нужно больше sampleCount)
- Плохое вложение (неверный delay или embeddingDim)
- Неустановившийся режим (недостаточный transient)

В норме **D₂ ≈ D_KY** для хаотических систем.

## Что это даёт

D_KY — **быстрая** (считается вместе со спектром), **устойчивая**
(не зависит от выбора r или embeddingDim), **теоретически обоснованная**
оценка размерности аттрактора.

## Ограничения

- Требует **полного** спектра Ляпунова (для N-мерных систем — N
  показателей).
- Работает как **верхняя граница** D₁ (информационной размерности), а не
  точное значение D₂.
- Для **гиперхаоса** (несколько положительных λ) формула даёт большее
  значение, чем D₂, и это правильно.

## Применения

- **Быстрая оценка размерности** — не нужно строить D₂
- **Проверка расчётов** — сравнение с D₂ выявляет ошибки
- **Теоретический анализ** — размерность в терминах показателей Ляпунова
