# Recurrence Quantification Analysis (RQA)

## Что это

**RQA** — метод анализа матрицы возвратов, показывающий, как часто
траектория возвращается в ε-окрестность ранее посещённых точек.

## Матрица возвратов

```text
R(i,j) = Θ(ε − ||xᵢ − xⱼ||)
```

где Θ — функция Хевисайда, ε — порог близости.

## Метрики

| Метрика | Что измеряет |
|---------|--------------|
| **RR** | Recurrence rate: плотность точек |
| **DET** | Determinism: доля точек в диагональных линиях |
| **LAM** | Laminarity: доля точек в вертикальных линиях |
| **L** | Средняя длина диагональной линии (предсказуемость) |
| **Lmax** | Максимальная длина |
| **ENTR** | Shannon энтропия длин диагоналей |

## Интерпретация

- **DET → 1** — регулярная динамика
- **DET → 0** — хаос или шум
- **LAM → 1** — «ламинарные» фазы
- **Большой Lmax** — периодические окна в хаосе

## Что смотреть в ChaosLab

1. Выберите систему.
2. Нажмите **RQA** в правой панели.
3. Отобразится матрица возвратов (чёрно-синие точки).

Метрики — в правой панели рядом с кнопкой.

## Параметры по умолчанию

- N = 600 точек
- embeddingDim = Dimension + 1 (макс. 4)
- delay = 8
- ε = 10-й процентиль медианного расстояния

## Применения

- Анализ ЭКГ (детекция аритмий)
- Климатология (рекуррентность состояний)
- Финансовые рынки (кризисы как возвраты)
- Анализ речи
