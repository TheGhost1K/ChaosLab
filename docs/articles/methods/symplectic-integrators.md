# Симплектические интеграторы

## Обзор

**Симплектический интегратор** — численный метод для **гамильтоновых**
систем, сохраняющий фазовый объём. В отличие от RK4, он **не дрейфует
энергию** при длительном интегрировании.

## Проблема RK4

Для гамильтоновых систем (например, Hénon-Heiles, гармонический
осциллятор) RK4 **медленно теряет энергию**: за 10 000 шагов дрейф
становится заметным, за 1 миллион — катастрофическим.

**Причина:** RK4 «вырезает» из фазового пространства куски — нарушает
симплектическую структуру.

## Verlet (leapfrog)

Простейший симплектический интегратор второго порядка. Для системы
с разделимым гамильтонианом `H = T(p) + V(q)`:

```text
p_{n+1/2} = p_n − (dt/2)·∇V(q_n)
q_{n+1}   = q_n + dt·p_{n+1/2}
p_{n+1}   = p_{n+1/2} − (dt/2)·∇V(q_{n+1})
```

Три подшага. Требуется **одно вычисление ∇V на шаг** — в 4 раза
дешевле RK4.

## Свойства

- **Точность:** O(dt²) — ниже RK4
- **Энергия:** сохраняется **точно** (не дрейфует, только колеблется)
- **Фазовый объём:** сохраняется (теорема Лиувилля)
- **Устойчивость:** для гамильтоновых систем **лучше** RK4

## Как включить в ChaosLab

1. Выберите **Hénon-Heiles** (единственная гамильтонова система в ChaosLab).
2. В блоке РЕНДЕР включите **Use Verlet**.
3. Рендерьте аттрактор.

Энергия будет сохраняться идеально. При использовании RK4 с тем же dt
энергия будет дрейфовать.

## Ограничения

- Требует разделимого гамильтониана `H = T(p) + V(q)`.
- Для диссипативных систем (Lorenz, Rössler) неприменим.
- Порядок точности ниже RK4 при одинаковом dt.
