# Фрактальная размерность Хигучи

## Обзор

**Higuchi Fractal Dimension** (1988) — метод оценки фрактальной размерности
**временного ряда напрямую**, без восстановления фазового пространства.

Альтернатива box-counting, но:
- Устойчива к самопересечениям траектории
- Менее шумная при малых N
- Работает по одномерному сигналу

## Алгоритм

1. Для каждого шага k = 1..k_max строим k подрядов:

```text
Xₖᵐ : x[m], x[m+k], x[m+2k], ..., m = 1..k
```

2. Считаем длину каждого подряда:

```text
Lₘ(k) = (1/k) · [(N−1)/(m_k · k)] · Σᵢ |x[m+ik] − x[m+(i−1)k]|
```

3. Усредняем по всем подрядам:

```text
L(k) = (1/k) · Σₘ Lₘ(k)
```

4. Наклон log L(k) vs log(1/k) = **D_H**.

## Интерпретация

| D_H | Тип сигнала |
|---|---|
| 1.0 | Периодический |
| 1.5 | Броуновское движение |
| 2.0 | Белый шум |
| **1.7–1.9** | **Хаос** |

Хаотические временные ряды обычно имеют D_H ≈ 1.7–1.9 — промежуточное
значение между периодикой и шумом.

## Что смотреть в ChaosLab

1. Выберите систему.
2. Нажмите **Higuchi FD**.
3. Результат — в разделе «СЛОЖНОСТЬ».

## Ожидаемые значения

| Система | D_H |
|---|---|
| Логистика (r = 4) | ≈ 1.0 |
| Lorenz (x-координата) | ≈ 1.5–1.7 |
| Hénon (x-координата) | ≈ 1.4–1.6 |
| Белый шум | ≈ 2.0 |

## Отличие от box-counting

| Свойство | Box-counting | Higuchi |
|---|---|---|
| Требует аттрактор в 2D/3D | Да | **Нет** |
| Устойчив к самопересечениям | Нет | Да |
| Работает при N < 500 | Нет | Да |
| Размерность | Аттрактора | **Временного ряда** |

**Важно:** Higuchi даёт размерность графика ряда, а не размерность
аттрактора. Для 1D-сигнала от аттрактора это **не то же самое**, что D₂.
Например, для Лоренца D₂ ≈ 2.06, но D_H(x-координаты) ≈ 1.5.

## Применения

- **Нейронауки** — фрактальная структура ЭЭГ
- **Физиология** — вариабельность сердечного ритма
- **Геофизика** — анализ сейсмических сигналов
- **Финансы** — фрактальный анализ рынков
